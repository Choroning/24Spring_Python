## 연습 문제 1: 거북이와 인사하기

**문제:** 터틀 그래픽의 대화 상자로 이름을 입력받아 이름을 넣은 인사말을 쓰고, 한 변의 길이가 100인 정사각형을 그리라. 문제 전문과 실행 예시는 [연습 문제 1](Exercises.ko.md#연습-문제-1-거북이와-인사하기)에 있다.

### 풀이

**접근 방법:** 입력은 `turtle.textinput()`으로, 출력은 거북이의 `write()`로 처리한다([3강 7절](Concepts_Lecture.ko.md#7-터틀-그래픽에서의-문자열-입출력)). 인사말은 고정된 두 문자열 사이에 입력받은 이름을 `+`로 접합하여 만든다([3강 4.1절](Concepts_Lecture.ko.md#41-접합)). 정사각형은 왼쪽으로 90도 돌고 100만큼 전진하는 동작을 네 번 반복하여 그린다.

- **입력:** `textinput()`은 입력한 이름을 문자열로 돌려주므로 변환 없이 바로 접합에 쓸 수 있다.
- **인사말:** `"안녕하세요? " + s + "씨, 터틀 인사드립니다."`는 세 문자열의 접합이다. `+`는 공백을 넣지 않으므로 물음표 뒤의 공백은 첫 번째 문자열에 직접 넣는다.
- **정사각형:** 거북이는 원점 (0, 0)에서 오른쪽(동쪽)을 바라보며 시작한다. `t.left(90)`은 거북이를 제자리에서 왼쪽으로 90도 돌리고, `t.forward(100)`은 바라보는 방향으로 100만큼 움직이며 선을 긋는다.
- **창 유지:** 마지막 줄의 `turtle.done()`은 명령 창에서 실행해도 그림 창이 바로 닫히지 않게 한다([3강 7.2절](Concepts_Lecture.ko.md#72-문자열-출력)).

**코드:**

```python
import turtle
t = turtle.Turtle()
t.shape("turtle")
s = turtle.textinput("", "이름을 입력하시오: ")
t.write("안녕하세요? " + s + "씨, 터틀 인사드립니다.")
t.left(90)
t.forward(100)
t.left(90)
t.forward(100)
t.left(90)
t.forward(100)
t.left(90)
t.forward(100)
turtle.done()
```

**실행 결과:** 대화 상자에 `홍길동`을 입력하면 원점에 `안녕하세요? 홍길동씨, 터틀 인사드립니다.`가 쓰이고, 거북이는 다음 순서로 움직여 원점의 왼쪽 위에 정사각형을 그린 뒤 원점으로 돌아온다. 인사말은 `write()`를 호출한 순간의 위치인 원점에서 오른쪽으로 쓰이므로, 그림 1처럼 정사각형의 오른쪽 아래 꼭짓점에서 시작한다.

| 명령 | 바라보는 방향 | 위치의 변화 |
|:-----|:-----|:-----|
| `t.left(90)`, `t.forward(100)` | 위 | (0, 0) → (0, 100) |
| `t.left(90)`, `t.forward(100)` | 왼쪽 | (0, 100) → (-100, 100) |
| `t.left(90)`, `t.forward(100)` | 아래 | (-100, 100) → (-100, 0) |
| `t.left(90)`, `t.forward(100)` | 오른쪽 | (-100, 0) → (0, 0) |

*표 1. 정사각형을 그리는 동안 거북이의 방향과 위치*

> **참고:** 터틀 그래픽의 좌표는 창의 가운데가 원점 (0, 0)이고, 오른쪽이 x가 커지는 방향, 위쪽이 y가 커지는 방향이다. 수학의 좌표평면과 같다.

## 연습 문제 2: 친근하게 대화하는 프로그램

**문제:** 이름과 나이를 입력받아 인사말, 이름의 길이, 내년의 나이를 출력하라. 문제 전문과 실행 예시는 [연습 문제 2](Exercises.ko.md#연습-문제-2-친근하게-대화하는-프로그램)에 있다.

### 풀이

**접근 방법:** 이름은 문자열 그대로 쓰고, 나이는 계산(나이 + 1)에 쓰므로 정수로 변환한다([3강 3.1절](Concepts_Lecture.ko.md#31-문자열을-숫자로-변환)). 이름의 길이는 `len()`으로 구한다([3강 5.3절](Concepts_Lecture.ko.md#53-문자열의-길이와-불변성)).

**코드:**

```python
print('안녕하세요?')
name = input('이름이 어떻게 되시나요? ')

print('만나서 반갑습니다. ' + name + "씨")
print('이름의 길이는 다음과 같군요:', end=' ')
print(len(name))

age = int(input("나이가 어떻게 되나요? "))
print("내년이면", str(age+1), "이 되시는군요.")
```

- **1~2행:** 인사말을 출력하고 이름을 입력받아 `name`에 저장한다. 큰따옴표와 작은따옴표를 섞어 썼지만 두 방식으로 만든 문자열은 같다.
- **4행:** 세 문자열을 접합하여 `만나서 반갑습니다. 홍길동씨`를 출력한다.
- **5행:** `print()`는 출력을 마친 뒤 줄 바꿈 문자를 출력하는데, `end=' '`를 주면 줄 바꿈 대신 공백 하나를 출력한다. 그래서 다음 `print()`의 출력이 같은 줄에 이어진다.
- **6행:** `len(name)`은 이름의 문자 수이다. `홍길동`은 한글 세 글자이므로 3이다. `len()`은 바이트 수가 아니라 문자 수를 센다.
- **8행:** 안쪽의 `input()`이 먼저 실행되어 문자열 `"21"`을 돌려주고, 바깥쪽의 `int()`가 이를 정수 21로 바꾸어 `age`에 저장한다.
- **9행:** `age+1`은 22이고 `str()`로 문자열 `"22"`가 된다. `print()`는 쉼표로 구분한 세 값 사이에 공백을 넣으므로 `내년이면 22 이 되시는군요.`가 출력된다.

**실행 결과:**

```text
안녕하세요?
이름이 어떻게 되시나요? 홍길동
만나서 반갑습니다. 홍길동씨
이름의 길이는 다음과 같군요: 3
나이가 어떻게 되나요? 21
내년이면 22 이 되시는군요.
```

> **참고:** 9행의 `str()`은 없어도 된다. `print()`가 쉼표로 받은 값을 스스로 문자열로 바꾸기 때문이다([3강 3.2절](Concepts_Lecture.ko.md#32-숫자를-문자열로-변환)). `22`와 `이` 사이의 공백 없이 자연스러운 문장으로 출력하려면 형식 지정자를 쓴다([3강 4.3절](Concepts_Lecture.ko.md#43-문자열-형식화)). `age + 1`을 괄호로 묶어야 `%` 연산보다 덧셈이 먼저 계산된다.
> ```python
> age = int(input("나이가 어떻게 되나요? "))
> print("내년이면 %d살이 되시는군요." % (age + 1))
> ```
> ```text
> 나이가 어떻게 되나요? 21
> 내년이면 22살이 되시는군요.
> ```

## 연습 문제 3: 친구 목록 만들기

**문제:** 친구 다섯 명의 이름을 입력받아 리스트에 저장했다가 출력하라. 문제 전문과 실행 예시는 [연습 문제 3](Exercises.ko.md#연습-문제-3-친구-목록-만들기)에 있다.

### 풀이

**접근 방법:** 빈 리스트를 만든 뒤, 이름을 하나 입력받을 때마다 `append()`로 리스트의 맨 뒤에 추가한다([3강 8.2절](Concepts_Lecture.ko.md#82-요소-추가)). 다섯 번 입력받은 뒤 리스트 전체를 출력한다.

- **빈 리스트:** `friend_list = [ ]`는 요소가 없는 리스트를 만든다. 대괄호 사이의 공백은 의미가 없다.
- **입력과 추가:** `friend = input(...)`과 `friend_list.append(friend)`를 다섯 번 반복한다. `friend`에는 매번 새 이름이 저장되지만, 이전 이름은 이미 리스트에 들어 있으므로 사라지지 않는다.
- **출력:** 리스트를 `print()`하면 대괄호와 따옴표를 포함한 리스트 표기로 출력된다. 요소는 추가한 순서대로 놓인다.

**코드:**

```python
friend_list = [ ]

friend = input("친구의 이름을 입력하시오: ")
friend_list.append(friend)

friend = input("친구의 이름을 입력하시오: ")
friend_list.append(friend)

friend = input("친구의 이름을 입력하시오: ")
friend_list.append(friend)

friend = input("친구의 이름을 입력하시오: ")
friend_list.append(friend)

friend = input("친구의 이름을 입력하시오: ")
friend_list.append(friend)

print(friend_list)
```

**실행 결과:**

```text
친구의 이름을 입력하시오: 홍길동
친구의 이름을 입력하시오: 강감찬
친구의 이름을 입력하시오: 이순신
친구의 이름을 입력하시오: 권율
친구의 이름을 입력하시오: 정약용
['홍길동', '강감찬', '이순신', '권율', '정약용']
```

> **참고:** 같은 두 줄을 다섯 번 적는 대신 반복문을 쓰면 코드를 한 번만 적고 횟수만 지정할 수 있다. `for i in range(5):`는 들여 쓴 두 줄을 다섯 번 실행하며, 반복문은 5강에서 다룬다. 실행 결과는 위와 같다.
> ```python
> friend_list = []
> for i in range(5):
>     friend = input("친구의 이름을 입력하시오: ")
>     friend_list.append(friend)
> print(friend_list)
> ```

## 연습 문제 4: 네 수의 평균

**문제:** 숫자 네 개를 입력받아 리스트에 저장하고, 그 평균을 출력하라. 문제 전문과 실행 예시는 [연습 문제 4](Exercises.ko.md#연습-문제-4-네-수의-평균)에 있다.

### 풀이

**접근 방법:** 연습 문제 3과 같이 빈 리스트에 값을 하나씩 추가하되, 평균을 계산해야 하므로 입력을 `int()`로 정수로 바꾸어 추가한다. 평균은 요소의 합을 요소의 개수로 나눈 값이다.

- **합:** 내장 함수 `sum()`은 리스트에 있는 수를 모두 더한 값을 돌려준다. `sum([10, 20, 30, 40])`은 100이다.
- **나눗셈:** `/`는 나누어떨어지더라도 결과를 항상 실수로 돌려주므로(2강) 100 / 4는 `25.0`이다.
- **출력:** `print("평균:", ...)`은 두 값 사이에 공백 하나를 넣어 `평균: 25.0`을 출력한다.

**코드:**

```python
nlist = []

n = int(input("숫자입력:"))
nlist.append(n)
n = int(input("숫자입력:"))
nlist.append(n)
n = int(input("숫자입력:"))
nlist.append(n)
n = int(input("숫자입력:"))
nlist.append(n)

print("평균:", sum(nlist) / 4)
```

**실행 결과:**

```text
숫자입력:10
숫자입력:20
숫자입력:30
숫자입력:40
평균: 25.0
```

평균이 정수가 아닌 경우도 정확히 계산된다. 1, 2, 3, 5를 입력하면 합이 11이므로 다음과 같이 11 / 4 = 2.75가 출력된다.

```text
숫자입력:1
숫자입력:2
숫자입력:3
숫자입력:5
평균: 2.75
```

> **주의:** `int()`로 바꾸지 않고 문자열을 그대로 리스트에 넣으면 `sum()`이 문자열을 더할 수 없어 `TypeError`가 발생한다. 또 나누는 수 4를 직접 적는 대신 `sum(nlist) / len(nlist)`로 쓰면 입력받는 개수가 바뀌어도 코드를 고칠 필요가 없다.
