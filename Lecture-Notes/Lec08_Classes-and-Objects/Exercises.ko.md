## 연습 문제 1: 원 클래스

**문제:** 원을 클래스 `Circle`로 표현하라. 원은 반지름(radius)을 비공개 인스턴스 변수로 가지며, 생성자에서 반지름을 받는다(생략하면 1.0). 반지름의 설정자 `setRadius()`와 접근자 `getRadius()`, 원의 넓이를 반환하는 `calcArea()`, 원의 둘레를 반환하는 `calcCircum()` 메서드를 정의한다. 반지름이 10인 원을 만들어 반지름, 넓이, 둘레를 출력한다. 원주율은 `math.pi`를 쓴다.

**실행 예시:**

```text
원의 반지름= 10
원의 넓이= 314.1592653589793
원의 둘레= 62.83185307179586
```

## 연습 문제 2: 은행 계좌 클래스

**문제:** 은행 계좌에는 돈을 저금할 수도 있고 인출할 수도 있다. 은행 계좌를 클래스 `BankAccount`로 모델링하라. 계좌는 현재 잔액(balance)만을 비공개 인스턴스 변수로 가지며, 잔액을 0으로 초기화하는 생성자와 저금 메서드 `deposit()`, 인출 메서드 `withdraw()`만 가진다. 두 메서드는 금액을 받아 잔액을 바꾸고 처리 내용을 출력한 뒤 바뀐 잔액을 반환한다. 계좌를 만들어 100원을 저금하고 10원을 인출한다.

**실행 예시:**

```text
통장에 100원이 입금되었음
통장에서 10원이 출금되었음
```

## 연습 문제 3: 고양이 클래스

**문제:** 고양이를 클래스 `Cat`으로 정의하라. 고양이는 이름(name)과 나이(age)를 비공개 속성으로 가지며, 생성자에서 두 값을 받는다. 각 속성의 설정자와 접근자를 정의하고, 3살인 Missy와 5살인 Lucky를 객체로 만들어 이름과 나이를 출력한다.

**실행 예시:**

## 연습 문제 4: 상자 클래스

**문제:** 상자를 나타내는 `Box` 클래스를 작성하라. `Box` 클래스는 가로 길이(width), 세로 길이(length), 높이(height)를 나타내는 비공개 인스턴스 변수를 가지며, 생성자에서 세 값을 받는다(생략하면 각각 0). 세 값의 설정자, 부피를 반환하는 `getVolume()`, 그리고 `print()`로 출력하면 `(가로, 세로, 높이)` 형태의 문자열이 나오게 하는 `__str__()`을 정의한다. 가로, 세로, 높이가 모두 100인 상자를 만들어 출력하고 부피를 출력한다.

**실행 예시:**

```text
(100, 100, 100)
상자의 부피는 1000000
```

## 연습 문제 5: 자동차 클래스

**문제:** 자동차를 나타내는 클래스 `Car`를 정의하라. 자동차 객체의 속성으로는 색상, 현재 속도, 현재 기어 등을, 동작으로는 기어 변속하기, 가속하기, 감속하기 등을 생각할 수 있다. 이 가운데 다음 속성과 동작만 골라 구현한다.

- **속성:** 속도 `speed`(기본값 0), 기어 `gear`(기본값 1), 색상 `color`(기본값 `"white"`)를 비공개 인스턴스 변수로 둔다.
- **동작:** 각 속성의 설정자 `setSpeed()`, `setGear()`, `setColor()`와, `(속도, 기어, 색상)` 형태의 문자열을 반환하는 `__str__()`을 둔다.

기본값으로 자동차를 만든 뒤 기어를 3, 속도를 100으로 바꾸고 자동차를 출력한다.

**실행 예시:**

```text
(100, 3, white)
```

## 연습 문제 6: 식별 번호를 가진 카운터

**문제:** 인스턴스 변수 `count`와 `id` 두 개를 가지는 클래스를 정의하라.

- 미리 정해진 리스트 `id_set = [3, 6, 10, 5, 2]`의 값을 차례로 생성되는 객체의 `id`에 넣어 객체 5개를 만든다.
- 각 객체의 `count`는 0에서 시작하며, 그 객체의 `id` 값만큼 1씩 증가시킨다.
- `id`가 짝수인 객체의 `id`와 `count` 값을 출력한다.

그다음 클래스를 쓰지 않고 리스트만 사용하여 같은 문제를 다시 풀라.

**실행 예시:** 두 프로그램의 출력은 같다.

```text
id = 6, count = 6
id = 10, count = 10
id = 2, count = 2
```
