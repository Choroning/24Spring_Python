## 연습 문제 1: `print()` 함수 실습

**문제:** 네 줄의 인사말을 출력하되, 셋째 줄의 72는 파이썬이 `9*8`을 계산하여 출력하게 하라. 문제 전문과 실행 예시는 [연습 문제 1](Exercises.ko.md#연습-문제-1-print-함수-실습)에 있다.

### 풀이

**접근 방법:** 한 줄을 출력할 때마다 `print()`를 한 번 호출한다. `print()`는 받은 값을 출력한 뒤 줄을 바꾸므로, 네 번 호출하면 네 줄이 출력된다([2강 4.2절](Concepts_Lecture.ko.md#42-print-함수)).

- **1, 2, 4행:** 큰따옴표 안의 문자열이 그대로 한 줄씩 출력된다. 문자열 안의 `?`와 `.`도 문자의 일부이다.
- **3행:** `print("9*8은", 9*8, "입니다.")`에는 인수가 세 개 있다. 첫 인수 `"9*8은"`은 따옴표 안에 있으므로 계산되지 않는 문자열이고, 둘째 인수 `9*8`은 따옴표 밖의 수식이므로 72로 계산된다. `print()`는 세 값 사이에 공백을 한 칸씩 넣어 `9*8은 72 입니다.`를 출력한다.

**코드:**

```python
print("안녕하세요? 여러분")
print("저는 파이썬을 무척 좋아합니다.")
print("9*8은", 9*8, "입니다.")
print("안녕히 계세요.")
```

**실행 결과:**

```text
안녕하세요? 여러분
저는 파이썬을 무척 좋아합니다.
9*8은 72 입니다.
안녕히 계세요.
```

> **참고:** 셋째 줄을 `print("9*8은 72 입니다.")`로 써도 같은 결과가 나오지만, 이때 72는 사람이 계산해 넣은 글자일 뿐이다. 수식을 인수로 넘기면 `9*8`을 `7*8`로 바꾸었을 때 출력되는 값도 저절로 56이 된다.

## 연습 문제 2: 로봇 기자

**문제:** 경기장, 이긴 팀, 진 팀, 우수 선수, 스코어를 입력받아 변수에 저장하고, 이를 문장에 넣어 야구 경기 기사를 출력하라. 문제 전문과 실행 예시는 [연습 문제 2](Exercises.ko.md#연습-문제-2-로봇-기자)에 있다.

### 풀이

**접근 방법:** 입력은 다섯 개의 문자열이므로 변수 다섯 개(`stadium`, `winner`, `loser`, `vip`, `score`)에 `input()`의 결과를 그대로 저장한다([2강 9.2절](Concepts_Lecture.ko.md#92-문자열-입력)). 스코어 `8:7`도 계산에 쓰지 않으므로 `int()`로 바꾸지 않고 문자열로 둔다. 출력은 `print()`에 변수와 고정된 문자열을 쉼표로 섞어 넘겨 만든다.

- **1, 8행:** `#`로 시작하는 주석이다. 입력 부분과 출력 부분이 하는 일을 설명하며 실행 결과에는 영향이 없다.
- **2\~6행:** 질문을 출력하고 사용자의 대답을 변수에 저장한다. 질문 끝에 공백을 한 칸 두어 입력한 글자가 물음표에 붙지 않게 한다.
- **9행:** `print("")`는 빈 문자열을 출력하고 줄을 바꾸므로 빈 줄이 하나 생긴다. 인수 없이 `print()`라고 써도 같다.
- **10, 15행:** `=`를 늘어놓은 문자열을 출력하여 기사의 위와 아래에 구분선을 만든다.
- **11\~14행:** 예를 들어 11행은 `"오늘"`, `stadium`의 값 `"서울"`, `"에서 야구 경기가 열렸습니다."`의 세 값을 공백으로 이어 `오늘 서울 에서 야구 경기가 열렸습니다.`를 출력한다.

**코드:**

```python
# Store the user's answers in variables.
stadium = input("경기장은 어디입니까? ")
winner = input("이긴 팀은 어디입니까? ")
loser = input("진 팀은 어디입니까? ")
vip = input("우수 선수는 누구입니까? ")
score = input("스코어는 몇 대 몇입니까? ")

# Combine the variables with fixed text to write the article.
print("")
print("===========================================")
print("오늘", stadium, "에서 야구 경기가 열렸습니다.")
print(winner, "과", loser, "은 치열한 공방전을 펼쳤습니다.")
print(vip, "이 맹활약을 하였습니다.")
print("결국", winner, "가", loser, "를", score, "로 이겼습니다.")
print("===========================================")
```

**실행 결과:**

```text
경기장은 어디입니까? 서울
이긴 팀은 어디입니까? 삼성
진 팀은 어디입니까? LG
우수 선수는 누구입니까? 홍길동
스코어는 몇 대 몇입니까? 8:7

===========================================
오늘 서울 에서 야구 경기가 열렸습니다.
삼성 과 LG 은 치열한 공방전을 펼쳤습니다.
홍길동 이 맹활약을 하였습니다.
결국 삼성 가 LG 를 8:7 로 이겼습니다.
===========================================
```

> **참고:** 기사 문장에는 어색한 곳이 두 가지 있다. 첫째, `print()`가 값 사이에 공백을 넣으므로 `서울 에서`처럼 이름과 조사 사이가 띄어진다. 둘째, 조사가 코드에 고정되어 있어 앞 낱말에 맞게 바뀌지 않는다. 한국어 조사는 앞 낱말의 마지막 글자에 받침이 있는지에 따라 `과`와 `와`, `은`과 `는`, `이`와 `가`, `을`과 `를`이 갈리므로, `삼성 가`는 `삼성이`, `LG 은`은 `LG는`이 되어야 자연스럽다. 공백 없이 문자열을 잇는 방법은 3강, 조건에 따라 다른 조사를 고르는 방법은 4강에서 다룬다.

## 연습 문제 3: 커피 가게 매출

**문제:** 아메리카노 2,000원, 카페라떼 3,000원, 카푸치노 3,500원일 때 메뉴별 판매 개수를 입력받아 총매출을 출력하라. 문제 전문과 실행 예시는 [연습 문제 3](Exercises.ko.md#연습-문제-3-커피-가게-매출)에 있다.

### 풀이

**접근 방법:** 총매출은 메뉴마다 (판매 개수 × 가격)을 구해 모두 더한 값이다. 가격은 변하지 않는 값이므로 프로그램 앞부분에서 변수에 저장해 두고, 판매 개수는 `int(input())`으로 정수로 입력받는다([2강 9.1절](Concepts_Lecture.ko.md#91-정수-입력-input과-int)).

- **1\~3행:** 메뉴별 가격을 변수에 저장한다. 가격이 바뀌면 이 세 줄만 고치면 된다.
- **5\~7행:** 판매 개수를 입력받아 정수로 바꾼다. `int()`를 빼면 판매 개수가 문자열이 되어 `*`가 곱셈이 아닌 문자열 반복이 되고 `+`는 문자열 접합이 되므로, 오류 없이 `1010101010...`처럼 1만 자가 넘는 긴 문자열이 출력된다.
- **9\~11행:** `sales`에 메뉴별 매출을 차례로 더해 간다. 10행과 11행의 오른쪽에서는 곱셈이 덧셈보다 먼저 계산되므로 괄호가 필요 없다.
- **12행:** 총매출을 출력한다.

**코드:**

```python
americano_price = 2000
cafelatte_price = 3000
cappuccino_price = 3500

americanos = int(input("아메리카노 판매 개수: "))
cafelattes = int(input("카페라떼 판매 개수: "))
cappuccinos = int(input("카푸치노 판매 개수: "))

sales = americanos * americano_price
sales = sales + cafelattes * cafelatte_price
sales = sales + cappuccinos * cappuccino_price
print("총 매출은", sales, "입니다.")
```

10, 20, 30을 입력했을 때 `sales`의 값은 다음과 같이 바뀐다.

| 행 | 계산 | `sales`의 값 |
|:-----|:-----|:-----|
| 9 | 10 × 2000 = 20000 | 20000 |
| 10 | 20000 + 20 × 3000 = 20000 + 60000 | 80000 |
| 11 | 80000 + 30 × 3500 = 80000 + 105000 | 185000 |

*표 1. 10, 20, 30을 입력했을 때 `sales`의 변화*

**실행 결과:**

```text
아메리카노 판매 개수: 10
카페라떼 판매 개수: 20
카푸치노 판매 개수: 30
총 매출은 185000 입니다.
```

> **참고:** 10행과 11행은 복합 대입 연산자로 `sales += cafelattes * cafelatte_price`, `sales += cappuccinos * cappuccino_price`처럼 쓸 수도 있다([2강 11.2절](Concepts_Lecture.ko.md#112-복합-대입-연산자)). 또 `sales = americanos * americano_price + cafelattes * cafelatte_price + cappuccinos * cappuccino_price`처럼 한 문장으로 계산해도 결과는 같다.

## 연습 문제 4: 자동 판매기

**문제:** 투입한 돈과 물건값을 입력받아 거스름돈과, 거스름돈으로 줄 500원짜리와 100원짜리 동전의 개수를 출력하라. 문제 전문과 실행 예시는 [연습 문제 4](Exercises.ko.md#연습-문제-4-자동-판매기)에 있다.

### 풀이

**접근 방법:** 거스름돈은 투입한 돈에서 물건값을 뺀 값이다. 500원짜리 동전의 개수는 거스름돈을 500으로 나눈 몫이고, 500원짜리로 주고 남은 금액은 500으로 나눈 나머지이다. 남은 금액을 100으로 나눈 몫이 100원짜리 동전의 개수이다([2강 10절](Concepts_Lecture.ko.md#10-나머지-연산자의-활용)). 5000원을 넣고 2600원짜리 물건을 사면 다음과 같다.

1. 거스름돈: 5000 - 2600 = 2400
2. 500원짜리 동전: 2400 // 500 = 4 (2000원)
3. 남은 금액: 2400 % 500 = 400
4. 100원짜리 동전: 400 // 100 = 4 (400원)

검산하면 4 × 500 + 4 × 100 = 2400이다.

**코드:**

```python
money = int(input("투입한 돈: "))
price = int(input("물건값: "))

change = money - price
print("거스름돈:", change)
coin500s = change // 500    # the quotient by 500 is the number of 500-won coins
change = change % 500       # compute the remainder after dividing by 500
coin100s = change // 100    # the quotient by 100 is the number of 100-won coins

print("500원 동전의 개수:", coin500s)
print("100원 동전의 개수:", coin100s)
```

- **4\~5행:** 거스름돈을 계산하여 `change`에 저장하고 출력한다.
- **6행:** 2400 // 500 = 4를 `coin500s`에 저장한다.
- **7행:** 2400 % 500 = 400을 다시 `change`에 저장한다. 같은 변수에 새 값을 대입하면 이전 값 2400은 사라지므로, 거스름돈 전체를 출력하는 5행은 이 줄보다 앞에 있어야 한다.
- **8행:** 400 // 100 = 4를 `coin100s`에 저장한다.

**실행 결과:**

```text
투입한 돈: 5000
물건값: 2600
거스름돈: 2400
500원 동전의 개수: 4
100원 동전의 개수: 4
```

> **주의:** 이 프로그램은 문제의 가정이 지켜질 때만 올바르다. 물건값이 100원 단위가 아니면, 예를 들어 2650원이면 거스름돈 2350원 가운데 500원짜리 4개와 100원짜리 3개로 2300원만 주고 50원은 돌려주지 않는다. 투입한 돈이 물건값보다 적으면, 예를 들어 1000원을 넣고 2600원짜리를 사면 거스름돈이 -1600으로 출력되고 동전 개수도 -4와 4라는 뜻 없는 값이 된다. 이런 입력을 걸러 내려면 조건문(4강)이 필요하다.

## 연습 문제 5: 평균 구하기

**문제:** `avg = x + y + z / 3`으로 세 수의 평균을 구한 프로그램이 10, 20, 30에 대해 40.0을 출력하는 원인을 찾아 고쳐라. 문제 전문과 코드는 [연습 문제 5](Exercises.ko.md#연습-문제-5-평균-구하기)에 있다.

### 풀이

**정답:** 4행의 `avg = x + y + z / 3`이 잘못되었다. `avg = (x + y + z) / 3`으로 고친다.

**해설:** 나눗셈 `/`는 덧셈 `+`보다 우선순위가 높으므로([2강 13.1절](Concepts_Lecture.ko.md#131-우선순위와-괄호)), 원래 수식은 세 수의 합을 3으로 나누지 않고 `z`만 3으로 나눈다.

- **잘못된 수식:** `x + y + z / 3`은 `x + y + (z / 3)`으로 계산된다. 10 + 20 + (30 / 3) = 10 + 20 + 10.0 = 40.0이다.
- **고친 수식:** `(x + y + z) / 3`은 괄호 안의 덧셈을 먼저 하여 (10 + 20 + 30) / 3 = 60 / 3 = 20.0이 된다.

**코드:**

```python
x = int(input("첫 번째 수를 입력하시오: "))
y = int(input("두 번째 수를 입력하시오: "))
z = int(input("세 번째 수를 입력하시오: "))
avg = (x + y + z) / 3
print("평균 =", avg)
```

**실행 결과:**

```text
첫 번째 수를 입력하시오: 10
두 번째 수를 입력하시오: 20
세 번째 수를 입력하시오: 30
평균 = 20.0
```

평균이 정수 20이 아니라 `20.0`으로 출력되는 것은 `/`가 나누어떨어질 때도 실수 결과를 내기 때문이다. 이 프로그램처럼 문법 오류 없이 실행되지만 의도와 다른 결과를 내는 잘못을 **논리 오류(logic error)** 라고 한다. 파이썬이 오류 메시지를 내지 않으므로, 손으로 계산한 값과 실행 결과를 비교하여 찾아야 한다.

## 연습 문제 6: 인사와 두 정수의 합

**문제:** 사용자의 이름을 입력받아 인사한 뒤, 두 정수를 입력받아 그 합을 출력하라. 문제 전문과 실행 예시는 [연습 문제 6](Exercises.ko.md#연습-문제-6-인사와-두-정수의-합)에 있다.

### 풀이

**문제 분석:** 프로그램을 작성하기 전에 입력, 출력, 필요한 데이터를 정리한다.

- **입력:** 사용자 이름, 2개의 정수
- **출력:** 입력한 사용자 이름(인사말), 입력한 정수와 그 합
- **데이터:** 이름을 나타내는 변수, 각 수를 나타내는 변수, 수의 합을 나타내는 변수

**변수 정하기:** 분석한 데이터마다 변수를 하나씩 정한다.

| 변수 | 뜻 | 자료형 |
|:-----|:-----|:-----|
| `name` | 입력한 이름 | 문자열 |
| `n1` | 첫 번째로 입력한 수 | 정수 |
| `n2` | 두 번째로 입력한 수 | 정수 |
| `Sum` | 입력한 수들의 합 | 정수 |

*표 2. 연습 문제 6에서 쓰는 변수*

**프로그래밍:** 함수 `input()`을 이용하여 입력받고, 정수는 `int()`로 변환한 뒤 두 정수의 합을 계산한다([2강 9절](Concepts_Lecture.ko.md#9-사용자-입력)).

**코드:**

```python
name = input("이름을 입력하시오: ")
print(name, "씨, 안녕하세요?")
print("파이썬에 오신 것을 환영합니다.")
n1 = int(input("첫 번째 정수를 입력하시오: "))
n2 = int(input("두 번째 정수를 입력하시오: "))
Sum = n1 + n2
print(n1, "과", n2, "의 합은", Sum, "입니다.")
```

- **1\~3행:** 이름을 문자열 그대로 `name`에 저장하고, 이름을 넣은 인사말을 두 줄 출력한다.
- **4\~5행:** 두 정수를 입력받아 `int()`로 변환하여 `n1`, `n2`에 저장한다.
- **6\~7행:** 합을 `Sum`에 저장하고, 두 수와 합을 문장으로 출력한다.

**실행 결과:**

```text
이름을 입력하시오: 홍길동
홍길동 씨, 안녕하세요?
파이썬에 오신 것을 환영합니다.
첫 번째 정수를 입력하시오: 300
두 번째 정수를 입력하시오: 400
300 과 400 의 합은 700 입니다.
```

**다른 방법: 형식 문자열 리터럴.** 7행의 문장은 **형식 문자열 리터럴(f-string)** 로 만들 수도 있다. 문자열의 따옴표 앞에 `f`를 붙이면, 문자열 안의 `{변수}` 자리에 그 변수의 값이 들어간다.

```python
message = f"{n1} 과 {n2} 의 합은 {Sum} 입니다."
print(message)
```

```text
300 과 400 의 합은 700 입니다.
```

형식 문자열 리터럴에서는 공백이 문자열에 쓴 그대로 들어가므로 `f"{n1}과 {n2}의 합은 {Sum}입니다."`처럼 쓰면 `300과 400의 합은 700입니다.`처럼 숫자와 글자를 붙여 출력할 수 있다. 쉼표로 값을 나열하는 `print()`에서는 이렇게 붙일 수 없다. 문자열 형식화는 3강에서 다룬다.

> **참고:** 합을 저장하는 변수 이름을 `Sum`으로 쓰면, 파이썬은 대소문자를 구분하므로 내장 함수 `sum()`의 이름을 가리지 않는다([2강 9.1절](Concepts_Lecture.ko.md#91-정수-입력-input과-int)). 다만 PEP 8은 대문자로 시작하는 이름을 클래스(8강)에 쓰도록 권하므로([2강 7.3절](Concepts_Lecture.ko.md#73-변수-이름의-규칙)), 변수에는 `total`처럼 소문자로 된 다른 이름을 쓰는 편이 관례에 맞다.

## 연습 문제 7: 두 정수의 사칙연산

**문제:** 두 정수를 입력받아 덧셈, 뺄셈, 곱셈, 나눗셈의 결과를 `4 + 2 = 6` 형식으로 출력하라. 문제 전문과 실행 예시는 [연습 문제 7](Exercises.ko.md#연습-문제-7-두-정수의-사칙연산)에 있다.

### 풀이

**문제 분석:**

- **입력:** 2개의 정수
- **출력:** 입력한 정수의 합, 차, 곱, 나눗셈 결과
- **데이터:** 각 수를 나타내는 변수, 각 연산의 결과를 나타내는 변수

**변수 정하기:** `n1`은 첫 번째로 입력한 수, `n2`는 두 번째로 입력한 수이고, `S`는 두 수의 합, `M`은 차, `Mul`은 곱, `Div`는 나눗셈 결과이다.

**프로그래밍:** 함수 `input()`을 이용하여 입력받아 `int()`로 정수형으로 변경하고, 두 정수의 네 가지 연산 결과를 변수에 저장한 뒤 출력한다([2강 8.2절](Concepts_Lecture.ko.md#82-산술-연산자)).

**코드:**

```python
n1 = int(input("첫 번째 정수를 입력하시오: "))
n2 = int(input("두 번째 정수를 입력하시오: "))
S = n1 + n2
M = n1 - n2
Mul = n1 * n2
Div = n1 / n2

print(n1, "+", n2, "=", S)
print(n1, "-", n2, "=", M)
print(n1, "*", n2, "=", Mul)
print(n1, "/", n2, "=", Div)
```

- **3\~6행:** 4와 2를 입력하면 `S`는 6, `M`은 2, `Mul`은 8, `Div`는 2.0이다. `/`는 나누어떨어져도 실수 결과를 내므로 `Div`만 `2.0`으로 출력된다.
- **8\~11행:** 예를 들어 8행은 `n1`, `"+"`, `n2`, `"="`, `S`의 다섯 값을 공백으로 이어 `4 + 2 = 6`을 출력한다. 연산자 기호는 따옴표 안에 있으므로 계산되지 않고 글자로 출력된다.

**실행 결과:**

```text
첫 번째 정수를 입력하시오: 4
두 번째 정수를 입력하시오: 2
4 + 2 = 6
4 - 2 = 2
4 * 2 = 8
4 / 2 = 2.0
```

> **주의:** 두 번째 정수로 0을 입력하면 6행의 `n1 / n2`에서 `ZeroDivisionError: division by zero` 오류가 나고 프로그램이 멈춘다. 출력 문장은 모두 6행 뒤에 있으므로 덧셈 결과도 출력되지 않는다. 0으로 나누지 않도록 미리 검사하려면 조건문(4강)이 필요하다. 몫과 나머지도 출력하려면 `print(n1, "//", n2, "=", n1 // n2)`, `print(n1, "%", n2, "=", n1 % n2)`를 더하면 된다.

## 연습 문제 8: 자릿수의 합

**문제:** 네 자리 이하의 0 이상인 정수를 입력받아 각 자릿수의 합을 출력하라(예: 1234이면 1 + 2 + 3 + 4 = 10). 문제 전문과 실행 예시는 [연습 문제 8](Exercises.ko.md#연습-문제-8-자릿수의-합)에 있다.

### 풀이

**문제 분석:**

- **입력:** 네 자리 이하의 정수
- **출력:** 입력한 정수의 자릿수의 합
- **데이터:** 수를 나타내는 변수, 각 자릿수를 나타내는 변수, 자릿수의 합을 나타내는 변수

**아이디어:** 입력한 수를 네 자리로 보고, 천의 자리를 알기 위해 1000으로 나눈 몫을 구한다. 천의 자리만큼을 빼고 남은 수에 대해 100으로 나눈 몫을 구하면 백의 자리가 되고, 같은 방식으로 10으로 나눈 몫이 십의 자리, 마지막에 남은 수가 일의 자리이다.

**변수 정하기:** `n`은 입력한 수, `R`은 앞 자릿수를 제외한 나머지 값, `S1`, `S2`, `S3`, `S4`는 천, 백, 십, 일의 자릿수, `Sum`은 각 자릿수의 합이다.

**코드:**

```python
n = int(input("네 자리 이하의 정수를 입력하시오: "))
S1 = n // 1000
R = n - (1000 * S1)
S2 = R // 100
R = R - (100 * S2)
S3 = R // 10
R = R - (10 * S3)
S4 = R
Sum = S1 + S2 + S3 + S4
print("자릿수의 합=%s" % Sum)
```

1234를 입력했을 때 변수의 값은 다음과 같이 바뀐다.

| 행 | 문장 | 계산 | 결과 |
|:-----|:-----|:-----|:-----|
| 2 | `S1 = n // 1000` | 1234 // 1000 | `S1` = 1 |
| 3 | `R = n - (1000 * S1)` | 1234 - 1000 | `R` = 234 |
| 4 | `S2 = R // 100` | 234 // 100 | `S2` = 2 |
| 5 | `R = R - (100 * S2)` | 234 - 200 | `R` = 34 |
| 6 | `S3 = R // 10` | 34 // 10 | `S3` = 3 |
| 7 | `R = R - (10 * S3)` | 34 - 30 | `R` = 4 |
| 8 | `S4 = R` | | `S4` = 4 |
| 9 | `Sum = S1 + S2 + S3 + S4` | 1 + 2 + 3 + 4 | `Sum` = 10 |

*표 3. 1234를 입력했을 때 변수 값의 변화*

10행의 `"자릿수의 합=%s" % Sum`에서 `%`는 나머지 연산자가 아니다. 왼쪽이 문자열이면 `%`는 문자열 안의 `%s` 자리에 오른쪽 값을 넣은 새 문자열을 만드는 문자열 형식화 연산자가 된다. 그래서 `자릿수의 합=10`이 출력된다. 문자열 형식화는 3강에서 다룬다.

**실행 결과:**

```text
네 자리 이하의 정수를 입력하시오: 1234
자릿수의 합=10
```

```text
네 자리 이하의 정수를 입력하시오: 3456
자릿수의 합=18
```

3456은 3 + 4 + 5 + 6 = 18이다. 405처럼 네 자리보다 짧은 수를 입력하면 `S1`이 0이 되어 0 + 4 + 0 + 5 = 9가 나오므로, 네 자리 이하의 수라면 모두 올바르게 계산된다.

**다른 방법: 나머지 연산자 이용.** 3행의 `n - (1000 * S1)`은 `n`을 1000으로 나눈 나머지 `n % 1000`과 같다. 그러므로 각 자릿수를 나머지 연산자로 바로 꺼낼 수 있다.

```python
n = int(input("네 자리 이하의 정수를 입력하시오: "))
Q1 = n // 1000
Q2 = (n % 1000) // 100
Q3 = (n % 100) // 10
Q4 = n % 10
print("자릿수의 합=%s" % (Q1 + Q2 + Q3 + Q4))
```

```text
네 자리 이하의 정수를 입력하시오: 1234
자릿수의 합=10
```

`n % 1000`은 1234에서 천의 자리를 떼어 낸 234, `n % 100`은 34, `n % 10`은 일의 자리 4이다. 이를 각각 100, 10, 1로 나눈 몫이 백, 십, 일의 자릿수가 된다. 마지막 줄에서 `Q1 + Q2 + Q3 + Q4`를 괄호로 묶은 것은 `%`가 `+`보다 먼저 계산되기 때문이다.

> **주의:** 두 풀이 모두 입력이 네 자리 이하의 0 이상인 정수라는 가정에 의존한다. 12345를 입력하면 `S1`이 12가 되어 12 + 3 + 4 + 5 = 24가 출력되지만, 올바른 답은 1 + 2 + 3 + 4 + 5 = 15이다. -1234를 입력하면 `//`가 더 작은 정수 쪽으로 내리므로 `S1`이 -2가 되어 17이 출력된다. 반복문(5강)을 쓰면 `n % 10`으로 일의 자리를 꺼내고 `n //= 10`으로 그 자리를 지우는 일을 `n`이 0이 될 때까지 되풀이하여, 자릿수에 관계없이 합을 구할 수 있다.
