## 연습 문제 2: 로봇 기자

**문제:** 사용자에게 경기장, 이긴 팀, 진 팀, 우수 선수, 스코어를 질문하여 대답을 변수에 저장하고, 이 문자열들에 문장을 붙여 야구 경기 기사를 작성하는 프로그램을 작성하라. 기사의 앞에는 빈 줄을 하나 두고, 기사의 위와 아래에는 `=`로 된 구분선을 출력한다.

**실행 예시:**

```text
경기장은 어디입니까? 서울
이긴 팀은 어디입니까? 삼성
진 팀은 어디입니까? LG
우수 선수는 누구입니까? 홍길동
스코어는 몇 대 몇입니까? 8:7

===========================================
오늘 서울 에서 야구 경기가 열렸습니다.
삼성 과 LG 은 치열한 공방전을 펼쳤습니다.
홍길동 이 맹활약을 하였습니다.
결국 삼성 가 LG 를 8:7 로 이겼습니다.
===========================================
```

## 연습 문제 4: 자동 판매기

**문제:** 자동 판매기를 시뮬레이션하는 프로그램을 작성하라.

- 자동 판매기는 사용자로부터 투입한 돈과 물건값을 입력받는다.
- 물건값은 100원 단위라고 가정한다.
- 프로그램은 거스름돈을 계산하여 출력한다.
- 자판기는 500원짜리와 100원짜리 동전만 가지고 있다고 가정한다. 거스름돈은 500원짜리 동전으로 줄 수 있는 만큼 먼저 주고, 나머지를 100원짜리 동전으로 준다.

**실행 예시:**

```text
투입한 돈: 5000
물건값: 2600
거스름돈: 2400
500원 동전의 개수: 4
100원 동전의 개수: 4
```

## 연습 문제 5: 평균 구하기

**문제:** 세 수를 입력받아 평균을 구하려고 다음 프로그램을 작성하였다. 그런데 10, 20, 30을 입력하면 평균이 20.0이 아니라 40.0으로 출력된다. 잘못된 부분은 어디인가? 원인을 설명하고 바르게 고쳐라.

```python
x = int(input("첫 번째 수를 입력하시오: "))
y = int(input("두 번째 수를 입력하시오: "))
z = int(input("세 번째 수를 입력하시오: "))
avg = x + y + z / 3
print("평균 =", avg)
```

**실행 예시 (잘못된 결과):**

```text
첫 번째 수를 입력하시오: 10
두 번째 수를 입력하시오: 20
세 번째 수를 입력하시오: 30
평균 = 40.0
```

## 연습 문제 8: 자릿수의 합

**문제:** 사용자로부터 정수를 입력받아서 정수의 자릿수의 합을 계산하는 프로그램을 작성하라. 예를 들어 1234의 자릿수의 합은 1 + 2 + 3 + 4 = 10이다. 입력은 네 자리 이하의 0 이상인 정수라고 가정한다.

**힌트:** 연산자 `//`를 사용한다.

**실행 예시:** 프로그램을 두 번 실행하여 각각 1234와 3456을 입력한 결과이다.

```text
네 자리 이하의 정수를 입력하시오: 1234
자릿수의 합=10
```

```text
네 자리 이하의 정수를 입력하시오: 3456
자릿수의 합=18
```
