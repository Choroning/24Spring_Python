## 연습 문제 1: 트레이스백으로 원인 찾기

**문제:** 다음 `grades.py`를 실행하면 아래의 트레이스백이 나온다.

```python
def letter(score):
    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    return "C"

def summary(records):
    lines = []
    for name, score in records.items():
        lines.append(name + ": " + letter(int(score)))
    return lines

data = {"Kim": "95", "Lee": "88", "Park": "7O"}
for line in summary(data):
    print(line)
```

```text
Traceback (most recent call last):
  File "grades.py", line 15, in <module>
    for line in summary(data):
                ~~~~~~~^^^^^^
  File "grades.py", line 11, in summary
    lines.append(name + ": " + letter(int(score)))
                                      ~~~^^^^^^^
ValueError: invalid literal for int() with base 10: '7O'
```

(1) 예외의 종류와 그 원인이 된 데이터를 쓰라. (2) Kim과 Lee의 결과가 출력되지 않은 이유를 설명하라. (3) 점수를 해석할 수 없는 사람은 `점수 오류('7O')`처럼 표시하고 나머지 사람의 결과는 그대로 출력하도록 `summary()`를 고쳐라.

**실행 예시:** 고친 프로그램의 출력이다.

```text
Kim: A
Lee: B
Park: 점수 오류('7O')
```

## 연습 문제 2: 범위가 있는 정수 입력

**문제:** 안내 문구 `prompt`를 보여 주고 정수를 입력받되, 정수가 아니면 `정수를 입력해야 한다: '입력'`을, `low` 이상 `high` 이하가 아니면 `low 이상 high 이하여야 한다`를 출력하고 다시 묻는 함수 `read_int(prompt, low, high)`를 작성하라. 올바른 값이 들어오면 그 정수를 반환한다. 이 함수로 1부터 12까지의 월을 입력받아 출력한다.

**실행 예시:** `삼월`, `13`, `3`을 차례로 입력한 결과이다.

```text
월을 입력하시오 (1~12): 삼월
정수를 입력해야 한다: '삼월'
월을 입력하시오 (1~12): 13
1 이상 12 이하여야 한다
월을 입력하시오 (1~12): 3
입력한 월: 3
```

## 연습 문제 3: 네 절의 실행 순서

**문제:** 다음 프로그램의 출력을 실행하지 않고 쓰라. `print(..., end=" ")`는 줄을 바꾸지 않고 공백 하나를 출력한다.

```python
def check(x):
    try:
        print("가", end=" ")
        r = 100 // x
        print("나", end=" ")
    except ZeroDivisionError:
        print("다", end=" ")
        return "zero"
    except TypeError:
        print("라", end=" ")
        raise
    else:
        print("마", end=" ")
        return r
    finally:
        print("바")

print(check(4))
print(check(0))
try:
    print(check("4"))
except TypeError:
    print("바깥에서 처리")
```

## 연습 문제 4: 사칙 연산 계산기

**문제:** `"3 + 4"`처럼 수, 연산자, 수를 공백으로 구분한 문자열을 받아 계산 결과(실수)를 반환하는 함수 `calc(expr)`를 작성하라. 다음 경우에는 예외를 처리하여 `"오류: "`로 시작하는 문자열을 반환한다.

- 0으로 나누면 `"오류: 0으로 나눌 수 없다"`를 반환한다.
- 연산자가 `+`, `-`, `*`, `/`가 아니면 함수 안에서 `ValueError("모르는 연산자 '연산자'")`를 일으키고, 그 예외를 같은 함수의 처리기에서 받아 메시지를 붙여 반환한다.
- 수로 바꿀 수 없거나 조각이 세 개가 아니면 파이썬이 일으킨 `ValueError`의 메시지를 붙여 반환한다.

**실행 예시:**

```text
3 + 4 => 7.0
10 / 4 => 2.5
1 / 0 => 오류: 0으로 나눌 수 없다
2 ^ 3 => 오류: 모르는 연산자 '^'
abc * 2 => 오류: could not convert string to float: 'abc'
1 + => 오류: not enough values to unpack (expected 3, got 2)
```

## 연습 문제 5: 여러 파일의 합계

**문제:** 파일 경로의 리스트를 받아, 각 파일의 줄마다 적힌 수를 모두 더하는 함수 `total_of_files(paths)`를 작성하라. 함수는 `(합계, 수가 아닌 줄의 수, 없는 파일의 리스트)`를 반환한다.

- 없는 파일은 건너뛰고 그 경로를 리스트에 모은다.
- 빈 줄은 무시한다.
- 수로 바꿀 수 없는 줄은 건너뛰고 그 개수를 센다.
- 한 파일이나 한 줄의 실패 때문에 나머지 처리가 멈추어서는 안 된다.

`a.txt`에 `10`, `20`, 빈 줄을, `b.txt`에 `1.5`, `둘`, `2.5`를 한 줄씩 저장한 뒤, `["a.txt", "nothing.txt", "b.txt"]`에 대해 호출한다.

**실행 예시:**

```text
(34.0, 1, ['nothing.txt'])
```

## 연습 문제 6: 입력 검증 예외의 계층

**문제:** 학생 정보 딕셔너리를 검사하는 함수 `validate(student)`와 다음 예외 클래스들을 정의하라.

- `ValidationError`: 모든 검증 오류의 상위 클래스이다. 문제가 된 항목의 이름 `field`를 속성으로 가지고, 메시지는 `"항목: 설명"` 형태이다.
- `EmptyFieldError`: `name`이나 `age`가 없거나 빈 문자열일 때의 오류이며, 설명은 `값이 비어 있다`이다.
- `RangeError`: `age`가 0 이상 150 이하가 아닐 때의 오류이며, 설명은 `값 200, 허용 범위 0~150` 형태이다.

`validate()`는 문제가 없으면 `True`를 반환한다. 세 학생 `{"name": "Kim", "age": 20}`, `{"name": "", "age": 20}`, `{"name": "Lee", "age": 200}`을 검사하되, 빈 칸 오류는 항목 이름만, 그 밖의 검증 오류는 메시지 전체를 출력한다.

**실행 예시:**

```text
{'name': 'Kim', 'age': 20} -> 통과
{'name': '', 'age': 20} -> 빈 칸: name
{'name': 'Lee', 'age': 200} -> 검증 실패: age: 값 200, 허용 범위 0~150
```

## 연습 문제 7: 설정 오류로 바꾸어 알리기

**문제:** `키 = 값` 형태의 줄로 된 설정 문자열을 해석하여 `(host, port)`를 반환하는 함수 `parse_config(text)`를 작성하라. 함수 안에서 생기는 낮은 수준의 예외는 모두 사용자 정의 예외 `ConfigError`로 바꾸어 일으키고, 원래 예외를 원인으로 연결한다.

- 빈 줄은 무시한다.
- `=`가 정확히 하나가 아닌 줄은 `"N번째 줄에 '='가 하나여야 한다: '줄'"`이라는 `ConfigError`가 된다.
- `port`가 없으면 `"port 설정이 없다"`, 정수가 아니면 `"port는 정수여야 한다: '값'"`이라는 `ConfigError`가 된다.

호출하는 쪽은 `ConfigError`만 처리하며, 메시지와 함께 원인 예외의 클래스 이름을 출력한다. 다음 네 문자열을 차례로 해석한다.

```text
"host = example.com\nport = 8080"
"host = a\nport = eighty"
"host = a"
"host a\nport = 1"
```

**실행 예시:**

```text
('example.com', 8080)
설정 오류: port는 정수여야 한다: 'eighty' | 원인: ValueError
설정 오류: port 설정이 없다 | 원인: KeyError
설정 오류: 1번째 줄에 '='가 하나여야 한다: 'host a' | 원인: ValueError
```

## 연습 문제 8: 되돌리는 컨텍스트 관리자

**문제:** 리스트를 받아 `with` 블록 안에서 그 리스트를 바꾸게 하되, 블록이 예외로 끝나면 리스트를 블록에 들어가기 전의 내용으로 되돌리는 컨텍스트 관리자 `Transaction(data)`를 작성하라.

- `with Transaction(리스트) as b:`의 `b`는 원래 리스트 자체이다.
- 예외로 끝나면 리스트를 되돌리고 `롤백: 예외클래스이름`을 출력한 뒤, 예외는 그대로 바깥으로 전달한다.
- 되돌릴 때 새 리스트를 만들지 말고 원래 리스트 객체의 내용을 바꾼다.

두 계좌의 잔액 `balances = [100, 50]`에서 첫 계좌의 돈을 둘째 계좌로 옮기는 `transfer(amount)`를 이 컨텍스트 관리자로 작성한다. 첫 계좌의 잔액이 음수가 되면 `ValueError("잔액 부족")`를 일으킨다. 30원을 이체한 뒤와 500원 이체에 실패한 뒤의 잔액을 출력한다.

**실행 예시:**

```text
[70, 80]
롤백: ValueError
이체 실패: 잔액 부족
[70, 80]
```
