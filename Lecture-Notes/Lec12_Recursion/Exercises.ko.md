## 연습 문제 1: 자릿수의 합과 자릿수

**문제:** 0 이상의 정수 `n`의 각 자리 숫자를 모두 더한 값을 반환하는 `digit_sum(n)`과, `n`의 자릿수를 반환하는 `num_digits(n)`을 재귀로 작성하라. 문자열로 바꾸지 않고 `//`와 `%`만 쓴다. 7, 1234, 9875, 1000000에 대해 수, 자릿수의 합, 자릿수를 출력한다.

**실행 예시:**

```text
7 7 1
1234 10 4
9875 29 4
1000000 1 7
```

## 연습 문제 2: 두 번 호출하는 재귀의 추적

**문제:** 다음 프로그램의 출력을 실행하지 않고 쓰라. 그리고 함수 `m`이 모두 몇 번 호출되는지 호출 트리를 그려 구하라.

```python
calls = 0

def m(n):
    global calls
    calls += 1
    if n <= 0:
        return
    m(n - 1)
    print(n, end=" ")
    m(n - 2)

m(3)
print()
print(calls)
```

## 연습 문제 5: 조합의 수

**문제:** $n$개 가운데 $k$개를 고르는 조합의 수 $\binom{n}{k}$는 다음 관계를 만족한다.

```math
\binom{n}{0} = \binom{n}{n} = 1, \qquad \binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k} \quad (0 < k < n)
```

이 관계를 그대로 옮긴 재귀 함수 `comb(n, k)`를 작성하고, 호출 횟수를 전역 변수로 세어 `comb(5, 2)`와 `comb(20, 10)`의 값과 호출 횟수를 출력하라. 그다음 `functools.lru_cache`를 붙인 `comb_memo(n, k)`로 `comb_memo(20, 10)`을 계산하여 값과 새로 계산한 횟수(`cache_info().misses`)를 출력하고, 마지막으로 표준 함수 `math.comb(20, 10)`의 값을 출력한다.

**실행 예시:**

```text
10 19
184756 369511
184756 120
184756
```

## 연습 문제 7: 폴더 크기의 합

**문제:** `pathlib.Path`를 받아, 파일이면 그 크기(바이트)를, 폴더이면 그 안의 모든 파일 크기의 합을 반환하는 `total_size(path)`를 재귀로 작성하라. 함수는 계산하면서 폴더와 파일을 들여쓰기로 출력한다. 폴더 이름 뒤에는 `/`를, 파일 이름 뒤에는 크기를 출력하고, 한 폴더 안의 항목은 이름순으로 처리한다.

먼저 다음 구조를 만든 뒤 `tree_demo`에 대해 호출한다. `a.txt`에는 `hello`와 줄바꿈을, `b.txt`에는 `한글`과 줄바꿈을 UTF-8로, `c.txt`에는 `x` 100개를 쓴다.

```text
tree_demo/
├── a.txt
└── docs/
    ├── b.txt
    └── old/
        └── c.txt
```

**실행 예시:**

```text
tree_demo/
  a.txt 6
  docs/
    b.txt 7
    old/
      c.txt 100
합계: 113
```

## 연습 문제 8: 반복으로 바꾼 이진 탐색

**실행 예시:**

```text
(617284, 17)
(-1, 20)
617284
True
```
