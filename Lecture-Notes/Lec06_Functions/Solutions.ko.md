## 연습 문제 1: 정사각형을 그리는 함수

**문제:** 정사각형을 그리는 함수 `square(length)`를 세 번 호출하여 (-200, 0), (0, 0), (200, 0)에서 시작하는 정사각형 3개를 그리라. 문제 전문과 실행 예시는 [연습 문제 1](Exercises.ko.md#연습-문제-1-정사각형을-그리는-함수)에 있다.

### 풀이

**접근 방법:** 정사각형을 그리는 일은 이미 함수 `square()`에 들어 있으므로, 남은 일은 거북이를 각 시작 위치로 옮긴 뒤 함수를 호출하는 것이다([6강 2.2절](Concepts_Lecture.ko.md#22-함수-호출과-실행-흐름)).

- **함수 `square(length)`:** 앞으로 `length`만큼 이동하고 왼쪽으로 90도 도는 일을 4번 반복한다. 네 번 돌면 모두 360도를 돌게 되므로, 거북이는 정사각형을 다 그린 뒤 출발점에서 처음과 같은 방향을 향한다.
- **선을 그리지 않고 이동하기:** `t.up()`으로 펜을 든 상태에서 `t.goto(x, y)`로 좌표 (x, y)로 이동하고, `t.down()`으로 펜을 다시 내린다. 펜을 든 동안의 이동은 선을 남기지 않는다.
- **세 번 호출:** 같은 함수를 인수 100으로 세 번 호출한다. 함수 정의는 한 번뿐이다.

**코드:**

```python
import turtle
t = turtle.Turtle()
t.shape("turtle")

def square(length):            # length is the side length
    for i in range(4):
        t.forward(length)
        t.left(90)

t.up()                         # lift the pen
t.goto(-200, 0)                # move to (-200, 0)
t.down()                       # put the pen down
square(100)                    # call square()

t.up()
t.goto(0, 0)
t.down()
square(100)

t.up()
t.goto(200, 0)
t.down()
square(100)
```

**실행 결과:** 텍스트는 출력되지 않으며, 터틀 그래픽 창에 연습 문제 1의 그림 1과 같은 정사각형 3개가 그려진다. 거북이는 처음에 오른쪽(동쪽)을 향하므로 각 정사각형은 시작점에서 오른쪽으로 한 변을 그린 뒤 왼쪽으로 돌며 시계 반대 방향으로 그려진다. 따라서 첫 번째 정사각형은 x가 -200\~-100, y가 0\~100인 영역을 차지하고, 시작점은 각 정사각형의 왼쪽 아래 꼭짓점이 된다. 마지막 정사각형을 그린 뒤 거북이는 (200, 0)에서 오른쪽을 향해 멈춘다.

위 코드에서는 펜을 들고, 옮기고, 내리고, 그리는 네 줄이 세 번 반복된다. 이 네 줄도 함수로 묶고 반복문으로 호출하면 더 짧아진다.

```python
import turtle
t = turtle.Turtle()
t.shape("turtle")

def square(length):            # length is the side length
    for i in range(4):
        t.forward(length)
        t.left(90)

def square_at(x, y, length):   # draw a square whose start corner is (x, y)
    t.up()
    t.goto(x, y)
    t.down()
    square(length)

for x in [-200, 0, 200]:
    square_at(x, 0, 100)
```

이 프로그램은 처음 프로그램과 같은 순서로 같은 동작(펜 들기, 이동, 펜 내리기, 이동과 회전 4번)을 세 번 수행하므로 같은 그림을 그린다. 함수 `square_at()` 안에서 다른 함수 `square()`를 호출하는 것처럼, 함수는 다른 함수를 부품으로 사용하여 더 큰 일을 할 수 있다. 정사각형을 네 개로 늘리려면 리스트에 시작 x 좌표를 하나 더하기만 하면 된다.

## 연습 문제 2: n각형을 그리는 함수

**문제:** 정 $n$각형을 그리는 함수 `n_polygon(n, length)`를 작성하고, 20도 회전과 정육각형 그리기를 10번 반복하라. 문제 전문과 실행 예시는 [연습 문제 2](Exercises.ko.md#연습-문제-2-n각형을-그리는-함수)에 있다.

### 풀이

**접근 방법:** 정 $n$각형을 그리려면 한 변을 그리고 바깥쪽으로 일정한 각도만큼 도는 일을 $n$번 반복한다. 볼록 다각형의 외각을 모두 더하면 360도이므로, 정 $n$각형의 한 외각, 즉 거북이가 한 꼭짓점에서 돌아야 하는 각도는 $360 / n$도이다. 정육각형이면 $360 / 6 = 60$도이다.

- **함수 `n_polygon(n, length)`:** 앞으로 `length`만큼 이동하고 왼쪽으로 `360//n`도 도는 일을 `n`번 반복한다. `n`번 돌면 모두 360도를 돌아 출발점에서 처음 방향으로 돌아온다.
- **반복 호출:** 왼쪽으로 20도 돌고 정육각형을 그리는 일을 10번 반복한다. 정육각형을 그리는 동안의 회전은 360도가 되어 방향을 바꾸지 않으므로, 다음 정육각형은 이전 정육각형보다 정확히 20도 돌아간 방향에서 시작한다.

**코드:**

```python
import turtle
t = turtle.Turtle()

# define a function that draws an n-sided polygon
def n_polygon(n, length):
    for i in range(n):
        t.forward(length)
        t.left(360//n)         # integer division uses //

for i in range(10):
    t.left(20)
    n_polygon(6, 100)
```

**실행 결과:** 텍스트는 출력되지 않으며, 연습 문제 2의 그림 2와 같은 그림이 그려진다. 모든 정육각형이 출발점을 한 꼭짓점으로 공유하고, 10개가 20도 간격으로 놓이므로 전체 $10 \times 20 = 200$도에 걸쳐 부채꼴처럼 퍼진 모양이 된다. 함수 `n_polygon()`은 모두 10번 호출되며, 거북이는 60번 이동하고 70번(정육각형 안에서 60번, 반복문에서 10번) 회전한다.

> **주의:** 정수 나눗셈 `360//n`은 $n$이 360의 약수일 때만 정확하다. 예를 들어 $n = 7$이면 $360 / 7 \approx 51.43$인데 `360//7`은 51이므로, 7번 돌아도 $7 \times 51 = 357$도밖에 돌지 않는다. 한 변이 100인 칠각형을 이렇게 그리면 거북이가 출발점에서 약 6.08만큼 떨어진 곳에서 멈추어 도형이 닫히지 않는다. 임의의 $n$에 대해 정확한 다각형을 그리려면 실수 나눗셈 `360/n`을 쓴다.

## 연습 문제 3: 전역 상수를 이용한 원의 넓이와 둘레

**문제:** 원주율을 전역 상수로 선언하고, 원의 넓이와 둘레를 계산하는 함수를 작성하여 입력받은 반지름에 대한 두 값을 출력하라. 문제 전문과 실행 예시는 [연습 문제 3](Exercises.ko.md#연습-문제-3-전역-상수를-이용한-원의-넓이와-둘레)에 있다.

### 풀이

**접근 방법:** 원의 넓이는 $\pi r^2$, 둘레는 $2 \pi r$이다. 두 식이 모두 원주율을 쓰므로 원주율을 전역 상수 `PI`로 한 번 정의하고, 각 식을 계산하는 함수 두 개가 이 상수를 읽게 한다([6강 5.5절](Concepts_Lecture.ko.md#55-전역-상수)).

- **전역 상수:** 대문자 이름 `PI`로 상수임을 나타낸다. 함수 안에서 읽기만 하므로 `global`문이 필요 없다.
- **계산 함수:** `circleArea(radius)`는 `PI*radius*radius`를, `circleCircumference(radius)`는 `2*PI*radius`를 반환한다.
- **`main()` 함수:** 입력과 출력을 담당하는 부분도 함수 `main()`으로 묶고, 프로그램의 맨 끝에서 한 번 호출한다.

**코드:**

```python
PI = 3.14159265358979          # global constant

def main():
    radius = float(input('원의 반지름을 입력하시오: '))
    print('원의 면적:', circleArea(radius))
    print('원의 둘레:', circleCircumference(radius))

def circleArea(radius):
    return PI*radius*radius

def circleCircumference(radius):
    return 2*PI*radius

main()
```

**실행 결과:** 첫 번째 실행은 실행 예시의 입력이고, 두 번째 실행은 반지름을 실수 2.5로 입력한 경우이다.

```text
원의 반지름을 입력하시오: 10
원의 면적: 314.159265358979
원의 둘레: 62.8318530717958
```

```text
원의 반지름을 입력하시오: 2.5
원의 면적: 19.634954084936187
원의 둘레: 15.70796326794895
```

반지름이 10이면 넓이는 $3.14159265358979 \times 10 \times 10 = 314.159265358979$, 둘레는 $2 \times 3.14159265358979 \times 10 = 62.8318530717958$이다. 반지름 2.5에 대한 결과에서 끝자리가 길게 나오는 것은 실수를 2진수로 저장할 때 생기는 표현 오차 때문이다.

- **함수의 정의 순서:** `main()`의 본체는 아래쪽에 정의된 `circleArea()`와 `circleCircumference()`를 호출하지만 오류가 나지 않는다. 본체는 `main()`이 호출될 때 실행되고, `main()`을 호출하는 마지막 줄은 세 함수가 모두 정의된 뒤에 있기 때문이다([6강 2.3절](Concepts_Lecture.ko.md#23-정의하기-전에-호출하면-생기는-오류)).
- **지역 변수:** `radius`는 `main()`의 지역 변수이고, 두 계산 함수의 매개변수 `radius`는 각 함수의 지역 변수이다. 이름은 같지만 서로 다른 변수이며, 호출할 때 인수로 값이 전달된다.

> **참고:** 표준 모듈 `math`에는 원주율 상수 `math.pi`(값 3.141592653589793)가 정의되어 있으므로, 실제 프로그램에서는 `import math` 뒤에 `math.pi`를 쓰는 것이 정확하고 편리하다. 또 PEP 8의 관례에 따르면 함수 이름은 `circleArea` 같은 camelCase보다 `circle_area`처럼 소문자와 밑줄로 짓는 것이 파이썬다운 이름이다.

## 연습 문제 4: 사칙 연산 함수와 키워드 인수

**문제:** 사칙 연산 함수 `add()`, `sub()`, `mul()`, `div()`를 작성하고, 키워드 인수로 호출하여 `10+20*30`을 계산하라. 문제 전문과 실행 예시는 [연습 문제 4](Exercises.ko.md#연습-문제-4-사칙-연산-함수와-키워드-인수)에 있다.

### 풀이

**접근 방법:** 각 함수는 매개변수 `a`, `b`를 받아 연산 결과를 `return`으로 반환한다. 결과를 반환하므로 한 함수의 호출을 다른 함수의 인수로 넣을 수 있다.

- **연산 순서:** `10+20*30`은 곱셈이 덧셈보다 먼저 계산되므로 `10 + (20*30)`이다. 따라서 곱셈 함수를 안쪽에, 덧셈 함수를 바깥쪽에 둔다.
- **키워드 인수:** `mul(a=20, b=30)`처럼 매개변수 이름을 지정하여 호출한다([6강 6.2절](Concepts_Lecture.ko.md#62-키워드-인수)).
- **실행 순서:** 인수는 함수가 호출되기 전에 계산되므로, `add(a=10, b=mul(a=20, b=30))`에서는 안쪽의 `mul(a=20, b=30)`이 먼저 실행되어 600을 반환하고, 이어서 `add(a=10, b=600)`이 610을 반환한다.

**코드:**

```python
def add(a, b):
    return a + b

def sub(a, b):
    return a - b

def mul(a, b):
    return a * b

def div(a, b):
    return a / b

result = add(a=10, b=mul(a=20, b=30))   # 10 + (20 * 30)
print(result)
print(sub(b=4, a=10), div(a=7, b=2))
```

**실행 결과:**

```text
610
6 3.5
```

첫 줄이 문제의 답 610이다. 둘째 줄은 나머지 두 함수를 확인한 것이다. `sub(b=4, a=10)`은 키워드 인수의 순서를 바꾸어 썼지만 이름으로 대응하므로 $10 - 4 = 6$이고, `div(a=7, b=2)`는 `/`가 실수 나눗셈이므로 3.5이다. 뺄셈과 나눗셈은 교환 법칙이 성립하지 않으므로, 키워드 인수로 어느 값이 `a`이고 어느 값이 `b`인지 밝히면 실수를 줄일 수 있다.

## 연습 문제 5: 세 정수 가운데 가장 큰 수

**문제:** 두 수에서 큰 수를 찾는 함수 `get_max()`를 이용하여, 세 정수 가운데 가장 큰 수를 반환하는 함수를 작성하라. 문제 전문은 [연습 문제 5](Exercises.ko.md#연습-문제-5-세-정수-가운데-가장-큰-수)에 있다.

### 풀이

**접근 방법:** 세 수 $x, y, z$의 최댓값은 먼저 $x$와 $y$ 가운데 큰 수를 구하고, 그 결과와 $z$ 가운데 큰 수를 구한 것과 같다. 즉 $\max(x, y, z) = \max(\max(x, y), z)$이다. 따라서 `get_max()`를 두 번 호출하면 되며, 첫 호출의 반환값을 두 번째 호출의 인수로 바로 넘긴다.

**코드:**

```python
def get_max(x, y):
    if x > y:
        return x
    else:
        return y

def get_max3(x, y, z):
    return get_max(get_max(x, y), z)

print(get_max3(10, 30, 20))
print(get_max3(30, 20, 10))
print(get_max3(10, 20, 30))
print(get_max3(-5, -9, -7))
print(get_max3(7, 7, 3))
```

**실행 결과:**

```text
30
30
30
-5
7
```

최댓값이 첫째, 둘째, 셋째 위치에 있는 경우, 모두 음수인 경우, 같은 값이 있는 경우를 시험하였다. 예를 들어 `get_max3(10, 30, 20)`은 `get_max(10, 30)`이 30을 반환하고, `get_max(30, 20)`이 다시 30을 반환한다. 이미 만든 함수를 부품으로 다시 쓰면 세 수를 비교하는 `if`문을 새로 작성하지 않아도 된다.

> **참고:** 파이썬에는 내장 함수 `max()`가 있어서 `max(10, 30, 20)`처럼 인수를 여러 개 주면 가장 큰 값 30을 반환한다. 이 문제는 함수를 조합하는 연습을 위해 `max()`를 쓰지 않았다.

## 연습 문제 6: 계산기 모듈

**문제:** 사칙 연산 함수를 모듈 `cals`로 만들고, 이 모듈로 `30+10/5*10`을 왼쪽부터 차례로 계산하라. 문제 전문은 [연습 문제 6](Exercises.ko.md#연습-문제-6-계산기-모듈)에 있다.

### 풀이

**접근 방법:** 모듈 이름이 `cals`이므로 파일 이름은 `cals.py`이다. 계산 함수들은 이 파일에 정의하고, 계산을 수행하는 프로그램 `main.py`는 같은 폴더에 두어 `import cals`로 모듈을 불러온다([6강 8.2절](Concepts_Lecture.ko.md#82-모듈의-작성과-사용)).

```text
cals_demo/
├── cals.py     모듈: add(), sub(), mul(), div()를 정의한다
└── main.py     프로그램: import cals로 모듈을 불러와 계산한다
```

*그림 1. 계산기 모듈과 프로그램의 폴더 배치*

- **우선순위 없이 계산하기:** 왼쪽부터 차례로 계산하므로 $30 + 10 = 40$, $40 / 5 = 8.0$, $8.0 \times 10 = 80.0$이다. 한 단계의 결과가 다음 단계의 첫 번째 인수가 된다.
- **모듈의 함수 호출:** `import cals`를 쓰면 함수를 `cals.add()`처럼 모듈 이름을 붙여 호출한다.

**코드:** `cals.py`는 다음과 같다.

```python
# cals.py: calculator module
def add(a, b):
    return a + b

def sub(a, b):
    return a - b

def mul(a, b):
    return a * b

def div(a, b):
    return a / b
```

`main.py`는 다음과 같다.

```python
import cals

# 30+10/5*10 evaluated from left to right, without operator precedence
step1 = cals.add(30, 10)      # 30 + 10
step2 = cals.div(step1, 5)    # (30 + 10) / 5
step3 = cals.mul(step2, 10)   # ((30 + 10) / 5) * 10
print(step3)

print(cals.mul(cals.div(cals.add(30, 10), 5), 10))
print(30+10/5*10)             # with Python's operator precedence
```

**실행 결과:** `cals_demo` 폴더에서 `python main.py`로 실행한 결과이다.

```text
80.0
80.0
50.0
```

첫 줄은 중간 결과를 변수에 저장하며 단계별로 계산한 값이고, 둘째 줄은 같은 계산을 함수 호출을 중첩하여 한 식으로 쓴 값이다. 중첩된 호출은 가장 안쪽의 `cals.add(30, 10)`부터 실행된다. 셋째 줄은 비교를 위해 파이썬의 연산자 우선순위를 그대로 적용한 값으로, 나눗셈과 곱셈이 먼저 계산되어 $30 + (10 / 5) \times 10 = 30 + 20.0 = 50.0$이 된다. `div()`가 실수 나눗셈 `/`를 쓰므로 결과는 실수이다.

`import cals`가 실행될 때 파이썬은 모듈 검색 경로의 첫 항목인 `main.py`의 폴더 `cals_demo/`에서 `cals.py`를 찾고, 이 파일을 한 번 실행하여 네 함수를 만든 뒤 모듈 객체를 이름 `cals`에 연결한다([6강 8.3절](Concepts_Lecture.ko.md#83-import문이-모듈을-찾는-방법)). 실행이 끝나면 `cals_demo/` 안에 컴파일된 파일을 담은 `__pycache__` 폴더가 생긴다. `cals.py`를 다른 폴더로 옮기면 `ModuleNotFoundError: No module named 'cals'`가 발생한다.

> **참고:** 모듈 이름이 길거나 자주 쓰이면 `import cals as c`로 별명을 붙여 `c.add(30, 10)`처럼 쓸 수 있다. `from cals import *`를 쓰면 모듈 이름 없이 `add(30, 10)`처럼 쓸 수 있지만, 현재 프로그램에 같은 이름의 함수가 있으면 덮어쓰므로 주의한다.
