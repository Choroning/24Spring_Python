## 연습 문제 1: 인코딩별 바이트 수

**문제:** 문자열 `text`를 받아 문자 수, UTF-8로 인코딩한 바이트 수, cp949로 인코딩한 바이트 수를 한 줄로 출력하는 함수 `byte_report(text)`를 작성하라. 문자열 `"Python"`, `"파이썬"`, `"Py파이썬3"`, `"가나다 ABC"`에 대해 호출하고, 마지막 줄에 `"한"`을 UTF-8로 인코딩한 바이트의 16진수 표기와 코드 포인트를 출력한다. 그리고 `"한"`(U+D55C)의 UTF-8 바이트를 비트 배치로 직접 계산하여 출력과 비교하라.

**실행 예시:**

```text
Python: 문자 6, UTF-8 6바이트, cp949 6바이트
파이썬: 문자 3, UTF-8 9바이트, cp949 6바이트
Py파이썬3: 문자 6, UTF-8 12바이트, cp949 9바이트
가나다 ABC: 문자 7, UTF-8 13바이트, cp949 10바이트
ed 95 9c 0xd55c
```

## 연습 문제 2: 줄, 단어, 문자 세기

**문제:** 텍스트 파일의 경로를 받아 줄 수, 단어 수, 문자 수를 튜플로 반환하는 함수 `count_file(path)`를 작성하라. 단어는 공백으로 구분된 덩어리이고, 문자 수에는 줄바꿈 문자도 넣는다. 파일 전체를 한꺼번에 메모리에 올리지 않아야 한다.

다음 네 줄(셋째 줄은 빈 줄)을 `notes.txt`에 저장한 뒤 함수를 호출한다.

```text
파일은 바이트의 나열이다
텍스트 파일은 인코딩을 따른다

with 문은 파일을 닫는다
```

**실행 예시:**

```text
(4, 11, 48)
```

## 연습 문제 3: 성적 파일의 집계

**문제:** 각 줄에 `이름 점수`가 있는 `scores.txt`를 읽어 인원, 평균, 최고점인 사람을 `result.txt`에 쓰라. 빈 줄과 `#`으로 시작하는 줄(주석)은 건너뛴다. 결과 파일은 `print()`의 `file` 매개변수로 쓰고, 평균은 소수점 아래 둘째 자리까지 쓴다. 프로그램은 먼저 다음 내용의 `scores.txt`를 만든다.

```text
# 이름 점수
Kim 85
Lee 92

Park 78

Choi 90
```

**실행 예시:** `result.txt`의 내용을 출력한 결과이다.

```text
인원: 4
평균: 86.25
최고: Lee 92
```

## 연습 문제 4: 번호를 붙이는 로그

**문제:** 메시지를 로그 파일의 끝에 `[001] 메시지` 형태로 한 줄 덧붙이는 함수 `log(message, path="app.log")`를 작성하라. 번호는 그 파일에 이미 있는 줄 수에 1을 더한 값을 세 자리로 쓴다. 파일이 아직 없으면 번호는 001부터 시작한다. 파일의 존재는 `pathlib`으로 확인한다.

`log()`를 세 번 호출한 뒤 로그 파일의 내용을 출력한다.

**실행 예시:** 로그 파일이 없는 상태에서 처음 실행한 결과이다.

```text
[001] 프로그램 시작
[002] 파일 3개 처리
[003] 프로그램 종료
```

같은 프로그램을 한 번 더 실행하면 기존 줄 뒤에 `[004]`부터 `[006]`까지가 덧붙는다.

## 연습 문제 5: 두 파일의 첫 차이

**문제:** 두 텍스트 파일을 앞에서부터 한 줄씩 비교하여, 처음으로 다른 줄의 번호(1부터)와 두 파일의 그 줄(끝의 줄바꿈 제외)을 튜플로 반환하는 함수 `first_difference(path1, path2)`를 작성하라. 두 파일이 끝까지 같으면 `None`을 반환한다. 한 파일이 먼저 끝나면 끝난 쪽의 줄은 빈 문자열로 본다. 두 파일을 동시에 열고 `readline()`으로 읽는다.

`v1.txt`에 `사과`, `배`, `포도`를, `v2.txt`에 `사과`, `배`, `귤`, `포도`를, `v3.txt`에 `사과`, `배`를 한 줄씩 저장한 뒤, `v1.txt`와 `v2.txt`, `v1.txt`와 `v1.txt`, `v1.txt`와 `v3.txt`를 비교한다.

**실행 예시:**

```text
(3, '포도', '귤')
None
(3, '포도', '')
```

## 연습 문제 6: 파일 종류의 판별

**문제:** 파일의 바이트를 이진 모드로 읽어 종류를 판별하는 함수 `detect(path)`를 작성하라. 다음 규칙을 위에서부터 차례로 적용한다.

1. PNG 서명 `89 50 4E 47 0D 0A 1A 0A`로 시작하면 `"PNG 그림"`이다.
2. UTF-8의 BOM `EF BB BF`로 시작하면 `"UTF-8 텍스트 (BOM)"`이다.
3. 모든 바이트가 ASCII(0\~127)이면 `"ASCII 텍스트"`이다.
4. 0 바이트가 없고 UTF-8로 오류 없이 디코딩되면 `"UTF-8 텍스트"`이다.
5. 그 밖에는 `"알 수 없는 이진 파일"`이다.

다음 여섯 파일을 만든 뒤 각각 판별한다. `a.png`는 PNG 서명 뒤에 0 바이트 8개, `b.txt`는 `"utf-8-sig"`로 쓴 `머리말`, `c.txt`는 `hello`, `d.txt`는 UTF-8로 쓴 `안녕하세요`, `e.txt`는 cp949로 쓴 `안녕하세요`, `f.bin`은 바이트 0, 255, 3, 128이다. 텍스트 파일의 끝에는 줄바꿈이 하나씩 있다.

**실행 예시:**

```text
a.png PNG 그림
b.txt UTF-8 텍스트 (BOM)
c.txt ASCII 텍스트
d.txt UTF-8 텍스트
e.txt 알 수 없는 이진 파일
f.bin 알 수 없는 이진 파일
```

## 연습 문제 7: CSV 성적표의 변환

**문제:** 열이 `name`, `korean`, `english`, `math`인 `grades.csv`를 읽어, 학생마다 총점 `total`과 소수점 아래 첫째 자리까지의 평균 `average` 열을 더하고, 총점이 높은 순서로 정렬하여 `report.csv`에 쓰라. 읽기와 쓰기에는 `csv.DictReader`와 `csv.DictWriter`를 쓴다. 프로그램은 먼저 다음 내용의 `grades.csv`를 `csv.writer`로 만든다.

```text
name,korean,english,math
Kim,85,90,78
Lee,92,88,95
Park,70,65,80
```

**실행 예시:** `report.csv`의 내용을 출력한 결과이다.

```text
name,korean,english,math,total,average
Lee,92,88,95,275,91.7
Kim,85,90,78,253,84.3
Park,70,65,80,215,71.7
```

## 연습 문제 8: JSON 설정 파일

**문제:** 프로그램의 설정을 JSON 파일로 저장하고 불러오는 두 함수를 작성하라.

- `load_settings(path)`: 기본 설정 `DEFAULTS = {"user": "guest", "volume": 5, "recent": []}`에서 시작하여, 설정 파일이 있으면 그 내용으로 기본값을 덮어쓴 딕셔너리를 반환한다. 파일이 없으면 기본 설정의 복사본을 반환한다. 몇 번을 불러와도 `DEFAULTS` 자체는 바뀌지 않아야 한다.
- `save_settings(path, settings)`: 설정을 사람이 읽기 좋게 들여 쓴 JSON으로 저장한다. 한글은 이스케이프하지 않는다.

설정을 불러와 출력하고, `volume`을 1 늘리고, `recent` 리스트에 `"보고서" + 볼륨 + ".txt"`를 덧붙여 저장한 뒤, 저장한 설정과 `DEFAULTS`를 출력한다.

**실행 예시:** 설정 파일이 없는 상태에서 처음 실행한 결과와 두 번째 실행한 결과이다.

```text
불러온 설정: {'user': 'guest', 'volume': 5, 'recent': []}
저장한 설정: {'user': 'guest', 'volume': 6, 'recent': ['보고서6.txt']}
기본값: {'user': 'guest', 'volume': 5, 'recent': []}
```

```text
불러온 설정: {'user': 'guest', 'volume': 6, 'recent': ['보고서6.txt']}
저장한 설정: {'user': 'guest', 'volume': 7, 'recent': ['보고서6.txt', '보고서7.txt']}
기본값: {'user': 'guest', 'volume': 5, 'recent': []}
```
