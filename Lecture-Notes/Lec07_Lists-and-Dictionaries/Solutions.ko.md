## 연습 문제 1: 피타고라스 삼각형

**문제:** 각 변의 길이가 1 이상 30 이하의 정수이고 $a \le b \le c$, $a^2 + b^2 = c^2$을 만족하는 조합 $(a, b, c)$를 리스트 컴프리헨션으로 모두 찾아 출력하라. 문제 전문과 실행 예시는 [연습 문제 1](Exercises.ko.md#연습-문제-1-피타고라스-삼각형)에 있다.

### 풀이

**접근 방법:** 가능한 모든 조합을 차례로 만들어 보고 조건을 만족하는 것만 남기는 **완전 탐색(exhaustive search)** 으로 푼다. 세 변의 길이를 동시에 바꿔 가야 하므로 `for` 절이 세 개인 리스트 컴프리헨션을 쓴다([7강 5.2절](Concepts_Lecture.ko.md#52-조건이-있는-리스트-컴프리헨션)).

- **범위:** 1 이상 30 이하의 정수는 `range(1, 31)`이다. `range`의 종료값은 범위에 포함되지 않으므로 31을 주어야 30까지 포함된다.
- **중복 제거:** `y`는 `x`부터, `z`는 `y`부터 시작하게 하여 $a \le b \le c$인 조합만 만든다. 그러면 (3, 4, 5)와 (4, 3, 5)처럼 같은 삼각형을 두 번 세지 않는다.
- **조건:** `x**2 + y**2 == z**2`가 참인 조합만 튜플 `(x, y, z)`로 새 리스트에 넣는다.

**코드:**

```python
new_list = [(x, y, z) for x in range(1, 31)
                      for y in range(x, 31)
                      for z in range(y, 31)
                      if x**2 + y**2 == z**2]
print(new_list)
```

**실행 결과:**

```text
[(3, 4, 5), (5, 12, 13), (6, 8, 10), (7, 24, 25), (8, 15, 17), (9, 12, 15), (10, 24, 26), (12, 16, 20), (15, 20, 25), (18, 24, 30), (20, 21, 29)]
```

리스트 컴프리헨션은 대괄호 안에서 줄을 바꾸어 써도 되므로, `for` 절마다 한 줄씩 쓰면 읽기 쉽다. 같은 동작을 중첩 반복문으로 쓰면 다음과 같으며, 왼쪽 `for` 절이 바깥 반복문에 대응한다.

```python
new_list = []
for x in range(1, 31):
    for y in range(x, 31):
        for z in range(y, 31):
            if x**2 + y**2 == z**2:
                new_list.append((x, y, z))
print(new_list)
```

```text
[(3, 4, 5), (5, 12, 13), (6, 8, 10), (7, 24, 25), (8, 15, 17), (9, 12, 15), (10, 24, 26), (12, 16, 20), (15, 20, 25), (18, 24, 30), (20, 21, 29)]
```

- **첫 조합의 추적:** `x`가 3, `y`가 4일 때 `z`는 4부터 30까지 바뀌며, `z`가 5일 때 $3^2 + 4^2 = 9 + 16 = 25 = 5^2$이므로 `(3, 4, 5)`가 추가된다.
- **결과의 순서:** 바깥 반복의 `x`가 작은 조합부터 추가되므로 결과는 첫 성분의 오름차순이다.
- **정수배 조합:** (6, 8, 10), (9, 12, 15), (12, 16, 20), (15, 20, 25), (18, 24, 30)은 (3, 4, 5)의 2~6배이고, (10, 24, 26)은 (5, 12, 13)의 2배이다. 정수배도 정리를 만족하므로 함께 출력된다.
- **검사 횟수:** $1 \le x \le y \le z \le 30$인 조합의 수는 $\binom{32}{3} = 4960$이다. 세 변수를 모두 1~30으로 돌리는 $30^3 = 27000$번보다 적게 검사한다.

> **주의:** 종료값을 `range(1, 30)`으로 쓰면 변의 길이가 29까지만 검사되어 (18, 24, 30)이 빠지고 조합이 10개만 출력된다. "30 이하"처럼 끝값을 포함하는 범위는 `range(1, 31)`로 써야 한다. 이처럼 범위의 끝을 하나 잘못 정하는 실수를 끝값 하나 차이 오류(off-by-one error)라고 한다.

## 연습 문제 2: 파티 동시 참석자

**문제:** 세트 `partyA = {"Park", "Kim", "Lee"}`, `partyB = {"Park", "Choi"}`에서 두 파티에 모두 참석한 사람을 출력하고, 한 곳 이상 참석한 사람과 A 파티에만 참석한 사람을 이름순으로 출력하라. 문제 전문과 실행 예시는 [연습 문제 2](Exercises.ko.md#연습-문제-2-파티-동시-참석자)에 있다.

### 풀이

**접근 방법:** 집합 연산으로 바로 풀린다([7강 10.4절](Concepts_Lecture.ko.md#104-부분-집합과-집합-연산)). 두 파티에 모두 참석한 사람은 교집합, 적어도 한 곳에 참석한 사람은 합집합, A 파티에만 참석한 사람은 차집합 $A - B$이다.

- **1번:** `partyA.intersection(partyB)`는 두 세트에 모두 있는 요소로 새 세트를 만든다. `partyA & partyB`와 같다.
- **2번:** `|`와 `-`로 합집합과 차집합을 구한 뒤 `sorted()`로 정렬된 리스트를 만들어 출력한다.

**코드 (1번):**

```python
partyA = set(["Park", "Kim", "Lee"])
partyB = set(["Park", "Choi"])

print("2개의 파티에 모두 참석한 사람은 다음과 같습니다.")
print(partyA.intersection(partyB))
```

**실행 결과:**

```text
2개의 파티에 모두 참석한 사람은 다음과 같습니다.
{'Park'}
```

**코드 (2번):**

```python
partyA = {"Park", "Kim", "Lee"}
partyB = {"Park", "Choi"}

either = partyA | partyB          # union
only_a = partyA - partyB          # difference

print("한 파티 이상 참석:", sorted(either))
print("A 파티에만 참석:", sorted(only_a))
```

**실행 결과:**

```text
한 파티 이상 참석: ['Choi', 'Kim', 'Lee', 'Park']
A 파티에만 참석: ['Kim', 'Lee']
```

- **`set([...])`와 `{...}`:** 1번은 리스트를 `set()`에 주어 세트를 만들고, 2번은 중괄호로 직접 만든다. 두 방법으로 만든 세트는 같다.
- **합집합:** `Park`은 두 파티에 모두 있지만 세트에서는 한 번만 나타나므로 합집합의 요소는 4개이다.
- **차집합:** `partyA - partyB`는 `partyA`에서 `partyB`에도 있는 `Park`을 뺀 `{'Kim', 'Lee'}`이다. `partyB - partyA`는 `{'Choi'}`로 결과가 다르다.

> **참고:** 2번에서 `sorted()`를 쓰는 이유는 문자열 세트의 출력 순서가 실행할 때마다 달라질 수 있기 때문이다([7강 10.2절](Concepts_Lecture.ko.md#102-소속-검사와-순회)). 예를 들어 `print(partyA | partyB)`는 어떤 실행에서는 `{'Choi', 'Kim', 'Lee', 'Park'}`, 다른 실행에서는 `{'Lee', 'Kim', 'Park', 'Choi'}`를 출력한다. 1번의 결과는 요소가 하나뿐이므로 순서의 문제가 없다.

## 연습 문제 3: 편의점 재고 관리

**문제:** 물건별 재고를 저장한 딕셔너리 `items`에서 입력받은 물건의 재고를 출력하라. 판매하지 않는 물건을 입력해도 오류로 멈추지 않게 한다. 문제 전문과 실행 예시는 [연습 문제 3](Exercises.ko.md#연습-문제-3-편의점-재고-관리)에 있다.

### 풀이

**접근 방법:** 물건 이름을 키, 재고를 값으로 하는 딕셔너리에서 키로 값을 조회한다([7강 11.2절](Concepts_Lecture.ko.md#112-값의-조회)). 먼저 키로 바로 조회하는 기본 프로그램을 보고, 없는 키를 처리하도록 고친다.

**코드 (기본):**

```python
items = {"커피음료": 7, "펜": 3, "종이컵": 2, "우유": 1, "콜라": 4, "책": 5}

item = input("물건의 이름을 입력하시오: ")
print(items[item])
```

**실행 결과:**

```text
물건의 이름을 입력하시오: 콜라
4
```

- **`input()`:** 입력한 문자열 `"콜라"`를 반환하며, 이 문자열이 그대로 키로 쓰인다.
- **`items[item]`:** 키 `"콜라"`에 연결된 값 4를 반환한다.

이 프로그램에 딕셔너리에 없는 `라면`을 입력하면 마지막 줄에 `KeyError: '라면'`이 출력되며 프로그램이 멈춘다. 키가 있는지 `in`으로 먼저 확인하면 이 오류를 막을 수 있다.

**코드 (없는 물건 처리):**

```python
items = {"커피음료": 7, "펜": 3, "종이컵": 2, "우유": 1, "콜라": 4, "책": 5}

item = input("물건의 이름을 입력하시오: ")
if item in items:                 # check the key before indexing
    print(items[item])
else:
    print("%s은(는) 판매하지 않는 물건입니다." % item)
```

**실행 결과:**

```text
물건의 이름을 입력하시오: 콜라
4
```

```text
물건의 이름을 입력하시오: 라면
라면은(는) 판매하지 않는 물건입니다.
```

- **`item in items`:** 딕셔너리에 대한 `in`은 키를 검사하므로, 판매하는 물건의 이름이면 `True`이다.
- **`%s` 형식화:** `%` 연산자로 문자열 안의 `%s` 자리에 입력한 이름을 넣는다([3강 4.3절](../Lec03_Data-Types/Concepts_Lecture.ko.md#43-문자열-형식화)). 받침 유무에 따라 조사가 달라지므로 `은(는)`으로 썼다.

> **참고:** `if`-`else` 대신 `print(items.get(item, 0))`처럼 `get()`에 기본값 0을 주면 판매하지 않는 물건의 재고를 0으로 출력한다. 재고가 0인 물건과 판매하지 않는 물건을 구별해야 하는지에 따라 두 방법 가운데 하나를 고른다.

## 연습 문제 4: 영한사전

**문제:** 빈 딕셔너리에 `'one'`, `'two'`, `'three'`와 그 뜻을 추가한 영한사전을 만들고, 입력받은 단어의 뜻을 출력하라. 문제 전문과 실행 예시는 [연습 문제 4](Exercises.ko.md#연습-문제-4-영한사전)에 있다.

### 풀이

**접근 방법:** `dict()`로 빈 딕셔너리를 만들고 `딕셔너리[키] = 값`으로 항목을 하나씩 추가한다([7강 11.1절](Concepts_Lecture.ko.md#111-키와-값)). 입력받은 단어를 키로 써서 뜻을 조회한다.

**코드:**

```python
english_dict = dict()             # empty dictionary

english_dict['one'] = '하나'
english_dict['two'] = '둘'
english_dict['three'] = '셋'

word = input("단어를 입력하시오: ")
print(english_dict[word])
```

**실행 결과:**

```text
단어를 입력하시오: one
하나
```

```text
단어를 입력하시오: two
둘
```

- **`dict()`:** `{}`와 같은 빈 딕셔너리를 만든다.
- **항목 추가:** `english_dict['one'] = '하나'`는 키 `'one'`이 없으므로 새 항목을 추가한다. 세 줄을 실행하면 딕셔너리는 `{'one': '하나', 'two': '둘', 'three': '셋'}`이 된다.
- **조회:** 입력한 문자열을 키로 하여 뜻을 찾는다. 없는 단어를 입력하면 연습 문제 3의 기본 프로그램처럼 `KeyError`가 난다.

이 프로그램은 실행할 때마다 단어를 하나만 찾는다. 여러 단어를 연이어 찾고, 사전에 없는 단어도 처리하려면 반복문과 `get()`을 쓴다. 다음 프로그램은 아무것도 입력하지 않고 Enter 키를 누르면 끝난다.

**코드 (반복 조회):**

```python
english_dict = {'one': '하나', 'two': '둘', 'three': '셋'}

while True:
    word = input("단어를 입력하시오: ")
    if word == "":                # an empty line ends the program
        break
    print(english_dict.get(word, "사전에 없는 단어입니다."))
```

**실행 결과:**

```text
단어를 입력하시오: one
하나
단어를 입력하시오: two
둘
단어를 입력하시오: four
사전에 없는 단어입니다.
단어를 입력하시오:
```

- **`while True`와 `break`:** 무한 루프를 돌다가 빈 문자열이 입력되면 `break`로 반복을 끝낸다([5강 6.4절](../Lec05_Loops/Concepts_Lecture.ko.md#64-무한-루프), [9.1절](../Lec05_Loops/Concepts_Lecture.ko.md#91-break문)).
- **`get(word, "사전에 없는 단어입니다.")`:** 키가 있으면 뜻을, 없으면 안내 문구를 반환하므로 오류 없이 다음 입력으로 넘어간다.

## 연습 문제 5: 다섯 수의 평균

**문제:** 정수 5개를 입력받아 리스트에 저장하고 그 평균을 출력하라. 문제 전문과 실행 예시는 [연습 문제 5](Exercises.ko.md#연습-문제-5-다섯-수의-평균)에 있다.

### 풀이

**접근 방법:** 빈 리스트를 만들고, 반복문으로 정수를 5번 입력받아 `append()`로 추가한다([7강 3.2절](Concepts_Lecture.ko.md#32-요소-추가)). 평균은 합을 개수로 나눈 값이므로 `sum()`과 `len()`으로 구한다([7강 4.2절](Concepts_Lecture.ko.md#42-길이-최솟값-최댓값)).

**코드:**

```python
numbers = []                      # the five integers are stored here

for i in range(5):
    n = int(input("정수를 입력하시오: "))
    numbers.append(n)

average = sum(numbers) / len(numbers)
print("평균=", average)
```

**실행 결과:**

```text
정수를 입력하시오: 1
정수를 입력하시오: 2
정수를 입력하시오: 3
정수를 입력하시오: 4
정수를 입력하시오: 5
평균= 3.0
```

- **입력과 저장:** `input()`이 반환한 문자열을 `int()`로 정수로 바꾼 뒤 리스트 끝에 추가한다. 반복이 끝나면 `numbers`는 `[1, 2, 3, 4, 5]`이다.
- **평균:** `sum(numbers)`는 15, `len(numbers)`는 5이다. 파이썬 3의 `/`는 나누어떨어져도 실수 나눗셈의 결과를 내므로 평균은 `3.0`으로 출력된다(2강).
- **`len()`을 쓰는 이유:** 개수를 5로 직접 쓰지 않고 `len(numbers)`로 구하면, 입력받는 개수를 바꾸어도 평균을 구하는 줄은 고칠 필요가 없다.

`sum()`을 쓰지 않고 합을 직접 누적하면 다음과 같다. 루프 변수 `n`에 리스트의 요소가 차례로 대입된다.

```python
numbers = []

for i in range(5):
    numbers.append(int(input("정수를 입력하시오: ")))

total = 0
for n in numbers:                 # add the elements one by one
    total += n

print("평균=", total / 5)
```

```text
정수를 입력하시오: 1
정수를 입력하시오: 2
정수를 입력하시오: 3
정수를 입력하시오: 4
정수를 입력하시오: 5
평균= 3.0
```

## 연습 문제 6: 주사위 눈의 확률

**문제:** `random` 모듈로 주사위를 1000번 던져 각 눈이 나온 횟수를 세고, 그 횟수를 1000으로 나눈 값을 각 눈이 나올 확률로 출력하라. 문제 전문과 실행 예시는 [연습 문제 6](Exercises.ko.md#연습-문제-6-주사위-눈의-확률)에 있다.

### 풀이

**접근 방법:** 눈 1~6이 나온 횟수를 저장할 칸 6개짜리 리스트 `counts`를 만들고, 던질 때마다 나온 눈에 해당하는 칸을 1 늘린다. 눈 $k$의 횟수는 인덱스 $k-1$에 저장한다.

- **주사위 던지기:** `random.randint(1, 6)`은 1 이상 6 이하의 정수 하나를 같은 확률로 반환한다(4강).
- **횟수 세기:** `counts = [0] * 6`은 0이 6개인 리스트이다. 눈이 `face`이면 `counts[face - 1] += 1`로 그 칸을 늘린다.
- **확률:** 반복이 끝난 뒤 각 칸의 값을 1000으로 나누어 출력한다.

**코드:**

```python
import random

counts = [0] * 6                  # counts[0] for face 1, ..., counts[5] for face 6

for i in range(1000):
    face = random.randint(1, 6)   # 1 <= face <= 6
    counts[face - 1] += 1

for face in range(1, 7):
    print("주사위가", face, "인 확률은", counts[face - 1] / 1000)
```

**실행 결과:** 실행할 때마다 값이 달라지며, 다음은 한 번 실행한 결과이다. 여섯 횟수 162, 180, 181, 170, 144, 163의 합은 1000이다.

```text
주사위가 1 인 확률은 0.162
주사위가 2 인 확률은 0.18
주사위가 3 인 확률은 0.181
주사위가 4 인 확률은 0.17
주사위가 5 인 확률은 0.144
주사위가 6 인 확률은 0.163
```

- **인덱스와 눈의 대응:** 리스트의 인덱스는 0부터 시작하고 주사위의 눈은 1부터 시작하므로 `face - 1`로 맞춘다. 출력할 때도 `range(1, 7)`로 눈 1~6을 돌며 `counts[face - 1]`을 읽는다. 눈 번호와 인덱스를 섞어 쓰면 다른 눈의 칸을 읽는 오류가 생기기 쉬우므로, 대응 규칙을 주석으로 적어 둔다.
- **리스트를 쓰는 이유:** 횟수를 변수 6개에 따로 저장하면 `if`문 6개로 눈마다 다른 변수를 늘려야 하지만, 리스트를 쓰면 `counts[face - 1] += 1` 한 줄로 끝난다. 눈이 100가지여도 코드는 같다.

> **[확률및통계]** 각 눈이 나올 실제 확률은 $1/6 \approx 0.1667$이고, 출력값은 1000번 시행에서 그 눈이 나온 비율인 **상대도수(relative frequency)** 이다. 큰 수의 법칙에 따라 시행 횟수 $n$이 커질수록 상대도수는 실제 확률에 가까워진다. 상대도수의 표준오차는 $\sqrt{p(1-p)/n} = \sqrt{(1/6)(5/6)/1000} \approx 0.0118$이므로, 1000번 던지면 각 값이 0.1667에서 표준오차의 두 배인 약 0.024 이내로 벗어나는 것이 자연스럽다. 위 결과에서 가장 많이 벗어난 0.144(차이 약 0.023)도 이 범위 안에 있다.

> **참고:** 횟수 대신 눈마다 비율을 저장하는 변수를 두고 그 눈이 나올 때마다 `0.001`을 더해 가면 `0.16700000000000012`처럼 끝자리에 오차가 붙은 값이 출력될 수 있다. 0.001은 2진수로 정확히 나타낼 수 없어 근삿값으로 저장되고, 덧셈을 반복하면 그 오차가 쌓이기 때문이다. 정수인 횟수를 센 뒤 마지막에 한 번만 나누면 이 문제를 피할 수 있다. 또 `import random` 다음에 `random.seed(2024)`처럼 시드를 고정하면 실행할 때마다 같은 결과를 얻는다.
